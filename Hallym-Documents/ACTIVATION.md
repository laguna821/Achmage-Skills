# hallym-kordoc 활성화·업데이트 기록

2026-10-07. 독립 스킬 1.0.0-rc.1 / Achmage 런타임 **0.4.174-74bdab8423b1aa78**.

공개 스킬 등록과 Achmage OS 수록, 사용자가 승인한 한림대·한글 문서 기본 선택을 적용했습니다. 스킬은 일반 Codex·Claude Code에도 독립 설치할 수 있습니다. Achmage 사용자의 런타임 업그레이드는 고정 버전 설치와 기기별 전역 지침 갱신을 함께 수행합니다.

## 기본 동작

“한림대 보고서 만들어줘”, “한글파일로 만들어줘”, “Markdown을 HWPX로 만들어줘”에 hallym-kordoc를 기본 선택합니다. 사용자가 지정한 다른 도구·기관·참조 양식은 우선합니다. 한글날·맞춤법·한국어 설명만으로 문서 생성을 시작하지 않습니다.

HWP는 읽고 참고하며 새 한글 파일은 HWPX입니다. 정확한 공식 서식이 없으면 공통 초안으로 표시합니다. 개인 양식은 스킬과 별도 저장소에 남기며 업데이트 때 보존합니다.

## Achmage 기기 업그레이드

해당 기기에서 “런타임 올려”라고 요청하면 에이전트가 현지 AI-Library/onboarding/kit.json과 bootstrap.py로 최신 릴리스를 검증·적용하도록 안내와 설치 절차를 갱신했습니다. 옛 런타임의 install-adapters만 반복하면 새 소스 버전은 가져오지 않습니다.

런타임은 고정 GitHub ZIP을 받아 전체 해시를 검증하고 각 현지 Codex·Claude 및 온보딩에서 발견한 계정 설정에 적용합니다. 최초 설치에 인터넷 또는 검증된 캐시가 필요합니다. 명시적으로 꺼 둔 정책과 수정된 설치본을 덮어쓰지 않습니다.

Node 20 이상이 필요합니다. Windows는 setup.ps1, Linux에서 Node가 없다면 번들 core/setup.sh를 읽고 **--install 없이** 실행해 준비한 Node 경로로 상위 scripts/run.mjs를 호출할 수 있습니다. Linux 실제 적용은 아래처럼 아직 미검증입니다.

기존 MCP 연결은 자동 재시작되지 않습니다. 새 연결에서 설치 버전과 실제 로드 버전 일치를 확인합니다.
