# 하루 (Haru) 설계 답변: 표현(Express), 상호작용(Interact), 글쓰기(Write) 단계

## 먼저 결론
시각 체계, 상태표, 문구표를 모두 만들었고, 키트(kit) 토큰으로 바로 적용할 수 있게 `theme.css`로 정리했어요. 한 줄 요약:
- **느낌:** 차분함과 또렷함이에요. 큰 굵은 제목, 보통 굵기의 할 일 제목, 흐린 보조 글씨 세 단계만 쓰고, 강조색은 네 곳(주 버튼, 체크된 동그라미, 선택, 포커스)에만 써요. `design-principles/delight/identify-the-emotion-you-want-to`
- **강조색(Accent):** 인디고(Indigo). 파랑은 기본 앱 느낌이 강하고, 초록은 어두운 모드에서 흰 글씨 대비가 2.02:1이라 탈락이에요. 인디고는 밝은 모드 6.12:1, 어두운 모드 3.51:1(굵은 글씨 기준 3:1 통과)이에요. `branding/best-practices/apply-your-apps-accent-color-judiciously`
- **글자 크기:** 좁은 화면은 iOS 크기, 넓은 화면에서 마우스 같은 정밀 포인터가 있으면 데스크톱(`hk-mac`) 크기예요. 넓어도 터치 기기(아이패드 세로)는 iOS 크기와 44px 버튼을 써요. 사이드바, 목록, 상세 세 창이 744~1000px에 들어가려면 13px 본문이 필요해서예요.
- **상태 색:** 경고(주황)와 성공(초록)은 아이콘에만 쓰고 글씨는 기본 색이에요. 회색 배경 위에서 이 색 글씨는 대비가 4.06~4.08:1로 모자라서예요. 지난 할 일과 진행도에는 색을 쓰지 않아요.
- **유리(Glass):** 떠 있는 탭 바와 스크롤 중인 내비게이션 바에만 써요. 목록, 시트, 알림창, 안내 줄에는 쓰지 않아요.
- **아이콘:** Lucide. 모든 화면의 동작과 이동 항목마다 이름과 접근성 이름을 정했어요. 알림창과 액션 시트에는 아이콘을 넣지 않아요(주의 기호 없음).
- **확인창(D01), 대표님 답변 반영:** 넓은 화면의 휴지통 비우기는 일반 스타일 알림창이고, 휴지통 비우기가 기본 버튼이라 Return으로 확인돼요. 좁은 화면은 위험 스타일 액션 시트예요. 모든 데이터 삭제와 가져오기 덮어쓰기는 위험 스타일에 기본 버튼 없음이에요. 항목 하나 영구 삭제는 휴지통 비우기를 따라가요.
- **구성원과 휴지통:** 프로젝트 구성원은 그대로 두고, 휴지통 자동 삭제는 없어요.

## 2단계 문서에서 바뀐 것
- 문구 용어를 하나로 맞췄어요. "지웠어요/지우기"는 "삭제했어요/삭제"로, "영구히 지울까요"는 "영구 삭제할까요"로 바꿨어요. 최근 검색 "지우기"만 글을 비우는 일이라 그대로예요.
- 프로젝트 시트 버튼 "완료"를 "만들기/저장"으로 바꿨어요. "완료"는 끝낸 할 일에만 쓰기 위해서예요.
- 사용자가 입력한 이름 뒤에는 조사를 바로 붙이지 않고 고정 명사를 거쳐요. 예: "‘{제목}’ 할 일을 삭제했어요".
- 실행 취소 메시지는 타이머 없이(`duration: 0`) 써야 해요. 키트 기본값은 8초라서 빌드에서 꼭 바꿔야 해요.
- S02 상단은 아이콘 두 개 대신 "새 프로젝트" 글자 버튼과 "새 할 일" 버튼으로 했어요. 같은 더하기 아이콘이 둘이면 헷갈려서예요.
- 구성원 행에 이름 바꾸기(연필) 버튼을 눈에 보이게 넣었어요. 이름을 눌러 수정하는 방법이 숨은 동작이 되지 않게 하려고요.

## 질문 (차단하는 질문은 없어요, 확인만 부탁드려요)
1. 강조색을 인디고로 해도 될까요? 지금은 대비 계산과 의미로만 비교했고, 화면이 없어서 나란히 그려 보지는 못했어요. 빌드 단계에서 S01에 세 색을 적용해 실제 크기로 보고 확정하는 걸 제안해요.
2. 넓은 화면에서 사이드바가 960px 아래에서 자동으로 숨는 것(240+360+360)과 목록 폭 360px은 계산해서 정한 값이에요. HIG에 숫자가 없어서 확인이 필요해요 [HIG none].
3. 새 할 일을 여는 단축키를 정해 주세요. 지금은 비워 뒀어요 [HIG none].

## 사용한 가정
- 밀도는 폭이 아니라 입력 장치로 나눠요(`pointer: fine`). 웹용 대응이라 [HIG transfer]예요.
- 제품 글자 크기 하한: 좁은 화면 13px, 넓은 화면 12px. HIG 최소(11px, 10px)보다 높게 잡은 [House] 값이에요.
- 키트에 없는 부품 세 개(완료 버튼, 게이지, 안내 줄)는 토큰으로 새로 만들어요. 완료 버튼은 체크박스 의미(`aria-checked`), 게이지는 `<meter>`로 글자 설명과 함께 써요.
- 내보내기 파일 이름은 `haru-YYYY-MM-DD.json`이에요.
