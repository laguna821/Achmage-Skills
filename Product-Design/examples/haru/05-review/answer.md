# 하루 front end 검토 요약 (소유자용)

검토 대상: `tests/e2e/04-build/` (https://laguna821.github.io/Achmage-Skills/Product-Design/examples/haru/04-build/). 390 px와 1280 px, 라이트와 다크, 대비 높이기(prefers-contrast: more)와 동작 줄이기(reduced motion), 키보드만으로 핵심 흐름까지 확인했어요. 자세한 내용은 `hig-review-report.md`에 있어요.

## 결과 한 줄
전체적으로 차분하고 깔끔하게 마감됐어요. 차단 문제(Blocker)는 1건, 주요 문제(Major)는 3건, 사소한 문제(Minor)는 13건이에요. 리디자인이 필요한 수준은 아니에요.

## 가장 중요한 다섯 가지
1. **(Blocker) S07 검색창 안내 문구 대비 부족.** 라이트 모드에서 #6C6C70 글자가 #E5E5EA 바탕 위에 4.16:1로, 기준 4.5:1에 못 미쳐요. 자동 점검 스크립트는 placeholder를 읽지 못해 놓쳤어요.
2. **(Major) 첫 실행에 예시 데이터가 들어가요.** 새 사용자가 남의 할 일 14개와 구성원 둘을 보게 되고, 계획서(S01)의 "처음 열었을 때 빈 상태 안내"는 실제로 나타나지 않아요. 빌드 노트에도 적혀 있지 않아요.
3. **(Major) 휴지통 비우기와 영구 삭제의 확인 창(1280 px).** 결정 D01은 "기본 버튼 없음, 삭제 스타일"인데, 실제로는 삭제 버튼에 포커스가 있어 Return만 눌러도 지워져요. 빌드 노트가 "owner answer 1"이라고 하지만, 결정 문서에는 그런 답이 없어요.
4. **(Major) 키보드 포커스가 자주 사라져요.** 빠른 추가 후, 할 일 열기 후, Delete 후에 포커스가 body로 가요. 행마다 Tab 정지가 3개라서 매번 20번 넘게 Tab을 눌러야 해요.
5. **(Minor 묶음) 마감 손질.** 날짜 선택이 브라우저 기본 입력(2026-11-04 형식)이에요. 스크롤 시 상단 유리 막대에 제목이 얼룩처럼 번져요. 1280 px에서 S02, S08, S09의 제목과 본문 열이 맞지 않아요. 되돌리기 메시지가 부제목을 가려요.

## 결정(D01 ~ D16) 이행 현황
- 결정대로 구현: D02, D04, D05, D06, D07, D08, D09, D10, D11, D12, D13, D14, D15, D16 (14개)
- 일부 다름: D01(휴지통 비우기, 영구 삭제의 데스크톱 알림만 다름), D03(날짜 선택기가 브라우저 기본 입력, 빌드 노트에 이미 밝힘)
- 누락: 없음. 다만 S01의 "첫 실행 빈 상태"는 예시 데이터 때문에 보이지 않아요.

## 잘된 점
- 색을 아끼고(액센트 하나), 지난 할 일도 빨간색 없이 글자로만 알려요.
- 삭제는 묻지 않고 되돌리기로 처리해요(타이머 없음, 8초 뒤에도 유지).
- 접근성 트리가 정확해요. 모든 아이콘 버튼에 이름이 있고, 체크 상태와 알림이 전달돼요.
- 32회 자동 점검에서 글자 크기 미달, 44/28 px 미달 터치 대상, 이름 없는 컨트롤은 0건이에요.
- 대비 높이기와 동작 줄이기가 제대로 작동해요. 글자 크기를 키워도 따라가요.

## 확인하지 못한 것
VoiceOver 등 실제 스크린 리더, 실제 터치와 iOS 키보드, 투명도 줄이기 설정, 두 탭 동시 사용, 브라우저 기본 날짜 선택 팝업 화면.
