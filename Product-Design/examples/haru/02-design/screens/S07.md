## Layout
- **Compact:** the field sits at the top under the toolbar title; results below; tab bar visible; opening a result pushes S04 or S03 inside the 검색 tab (D14). Virtual keyboard: search type, Return reads 검색 `virtual-keyboards/best-practices/consider-customizing-the-return-key-type`; field has a clear button `text-fields/platform-considerations/ios-ipados/display-a-clear-button-in-the`.
- **Regular:** sidebar item 검색; the field at the top of the list pane; results below; detail pane shows S04 of the selected result; selecting a project result navigates the sidebar to that project (S03).
- Spacing multiples of 4 px; targets 44 px / 28 px [House 11].

## Component decisions
D04 (none, no filter), D06, D07, D09, D13, D14, D15.

## Lenses
**Attention:** the field is the only focus; results grouped; no accent color beyond the toolbar button and checked states. **Flow:** one place for all content; leaving search keeps the typed query and scroll for next visit within the session; Back from S04 returns to the same result; recent searches stay local and can be cleared.

## Why-chain
People look for, not browse → Agency → search with a prominent place and a stated scope → Search field in a tab / sidebar item → `searching/best-practices/if-search-is-important-give-it` `searching/best-practices/clearly-display-the-current-scope-of` → [HIG transfer]
