## Layout
- **Compact:** full-width pushed screen; toolbar with Back (standard, to the list it came from), title "할 일", and 삭제 in a "더 보기" menu or as a plain button. Fields stacked, label above value. Tab bar stays visible. When the keyboard opens, the focused field stays visible `virtual-keyboards/platform-considerations/ios-ipados/use-the-keyboard-layout-guide-to`. Text keyboard for title and note; Return in the title moves on `virtual-keyboards/best-practices/choose-a-keyboard-that-matches-the`.
- **Regular:** detail pane to the right of the list; close control (X) to clear the pane; same field order. Label and value side by side in a grouped form; reading column at most 720 px [House 11].
- Grouping: title block; metadata block (date, project, assignee); note. Space between blocks `layout/visual-hierarchy/group-related-items-to-clearly-express`. Targets 44 px compact, 28 px regular `accessibility/mobility/offer-sufficiently-sized-controls`.

## Data entry
- Choices instead of typing for date, project, assignee; typing only for title and note `entering-data/best-practices/when-possible-offer-choices-instead-of`.
- Title required: an empty title is not saved; the field shows the old title back and a short hint on leaving it empty `entering-data/best-practices/dynamically-validate-field-values`. No Save button.

## Lenses
**Attention:** the title is the largest element at the top; metadata is quieter, uniform rows; note last; delete is not prominent `buttons/role/dont-assign-the-primary-role-to`; no accent color except focus and the checked state.
**Flow:** reached from S01, S03, S07; edits autosave so no exit blocks; Back or Close always visible; changing project may move the task in other lists, which the list shows on return; resize across 744 px keeps this task open `design-principles/flexibility/preserve-a-persons-context`.

## Why-chain
Edit one task fully, with no mode → Agency → fields saved as typed, choices over typing → Pushed screen / detail pane with pop-ups → `file-management/saving-work/help-people-be-confident-that-their` `entering-data/best-practices/when-possible-offer-choices-instead-of` → [HIG transfer]

## Assumptions
- Unsaved typing is flushed on blur and on leaving; no Save button · Why: flow-map relaunch rule · Confirm with: front-end developer.
