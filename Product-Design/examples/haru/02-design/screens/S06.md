# Screen spec S06 프로젝트 만들기·편집 (Create or edit project)

## Identity
- Name: 프로젝트 만들기 / 프로젝트 편집 · Medium: web app · Size: compact (bottom sheet) and regular (sheet, centered)
- Job: make or change a project. `design-principles/purpose/create-value`
- Container: a short scoped task, not tied to one control, so a sheet at both classes (`alerting-and-confirming` step 7) `sheets/best-practices/for-complex-or-prolonged-user-flows` (short, so no alternative needed). Popover is not used because the task is not a few quick settings of one control and compact forbids it `popovers/platform-considerations/ios-ipados/avoid-displaying-popovers-in-compact-views`.

## Layout
- **Compact:** bottom sheet, name field then member list, bar on top. Keyboard layout guide as in S05.
- **Regular:** centered sheet over a dimmed S02/S03, content width small (about the reading width or less, set in visual stage). Bar at the top of the sheet.
- Spacing multiples of 4 px, targets 44 px compact, 28 px regular [House 11]; member rows are full-row targets.

## Data entry
- Name: required, not empty; 완료 is disabled while empty with a hint `entering-data/best-practices/dynamically-validate-field-values`. Duplicate names allowed but shown with a note (people may reuse) [assumption].
- Members: choices, not typing. To add a new member the person goes to S09; a short link "구성원 관리" under the list [assumption] keeps it reachable without nesting sheets `sheets/best-practices/display-only-one-sheet-at-a`.

## Component decisions
D02, D08, D10 (cut), D15.

## Lenses
**Attention:** name field first and focused; one prominent button; delete is quiet and last. **Flow:** opened from S02 (create) or S03 (edit); every exit visible; after Done, S03 shows the new project (create) or updated header; one sheet at a time.

## Why-chain
Short scoped create/edit → Agency, Simplicity → sheet with Done and Cancel → Sheet → `modality/best-practices/present-content-modally-only-when-theres` `sheets/best-practices/provide-an-alternative-to-the-done` → [HIG transfer]

## Assumptions
- Edit applies on 완료 (not autosave) · Why: it is a sheet with Done/Cancel, unlike S04 · Confirm with: product owner.
- Members default to all workspace members checked? No: only 나 checked · Why: smaller default · Confirm with: product owner.
