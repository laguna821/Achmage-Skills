# Screen spec S09 설정·구성원 (Settings and members)

## Identity
- Name: 설정 · Medium: web app · Size: compact (tab) and regular (sidebar item)
- Job: manage the workspace people, keep a backup, and reach the trash. `design-principles/responsibility/keep-peoples-information-safe`
- Few settings, good defaults: no appearance toggle (follows the system), no language picker `settings/best-practices/minimize-the-number-of-settings-you` `settings/best-practices/aim-to-provide-default-settings-that` `dark-mode/best-practices/avoid-offering-an-app-specific-appearance`.

## Layout
- **Compact:** grouped sections in one column under the large title 설정; tab bar visible. Add-member row is the last row of 구성원. Keyboard layout guide for the add field.
- **Regular:** list pane shows the same sections; reading column at most 720 px [House 11]; detail pane is unused (empty) or the list pane is wider [assumption: S09 uses the list and detail panes as one column].
- Grouping by section headers and space `layout/visual-hierarchy/group-related-items-to-clearly-express`; the destructive button has extra space from export/import `accessibility/mobility/consider-spacing-between-controls-as-important`.

## Component decisions
D01, D02, D12, D15.

## Lenses
**Attention:** quiet screen; no prominent button; destructive action last and plain; the storage line is plain text, not a warning color. **Flow:** the backup lives where people look for settings `settings/general-settings/put-general-infrequently-changed-settings-in`; delete-all points to export first; import never changes data before the confirmation.

## Why-chain
Data lives only in the browser → Responsibility → say so, offer export/import → Plain text + buttons in settings, confirmation for irreversible → `design-principles/responsibility/be-fully-transparent-about-what-your` `design-principles/responsibility/keep-peoples-information-safe` → [HIG]

## Assumptions
- Export format is JSON; import accepts only files exported by 하루 · Why: no backend · Confirm with: front-end developer.
- Import merge rule (D01) · Confirm with: product owner.
