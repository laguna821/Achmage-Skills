7 · Sheet

Native dialog. Bottom sheet with a grabber on compact (drag it down to dismiss), centered form sheet on regular. Cancel leads, the confirming action is Bold and trails. Escape closes; focus returns to the opener. Type something, then press Escape: unsaved changes ask first in an action sheet.

8 · Alert

Native dialog with role alertdialog. A specific title, a short message, one to three buttons. The destructive style is used only for the rare, irreversible action; with it there is a Cancel and no default button. Escape cancels; the backdrop does not.

A button that opens role="menu". Arrow keys, Home, End and type-ahead move; Enter or Space chooses; Escape closes and returns focus to the button. Checkmarks show state, a destructive item comes last.
