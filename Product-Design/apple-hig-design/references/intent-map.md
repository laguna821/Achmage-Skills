# Intent map

Name what the person wants to do, find the row, follow it to the HIG pattern page, then open the component cards listed. Where several components compete, the note under the group links the decision tree. Rows marked [HIG none] under Pattern have no pattern page: the component card carries the guidance. Rule IDs point to the rule index.
