# 노먼 도어 90초: 제작 기록

영상 대본 스킬로 쓴 시험 대본(노먼 도어, 90초, 카드 16장)을 Motion Art Director 4.1.0으로 끝까지 만든 기록입니다. 목적은 영상 한 편을 얻는 것보다, 대본의 장면 제안이 실제 제작에서 어디까지 통하는지 보는 것이었습니다. 만든 날은 2026-11-12입니다.

## 파일

| 파일 | 내용 |
|---|---|
| `norman-door-90s-1080p.mp4` | 완성본. 1920x1080, 30fps, 90초 |
| `script-as-produced.json` | 영상을 만든 대본 (카드 16장, 90초) |
| `script-revised.json` | 제작에서 바뀐 것을 대본에 되돌려 적은 판. 문장은 같고 장면 제안, 화면 범위, 사건 수, 화면 속 글자, 노출 시간 두 곳을 고쳤습니다(92초) |
| `rough-cut-sheet.html` | 두 대본의 가편집 시트. 위쪽 탭으로 바꿔 봅니다 |
| `overview.jpg` | 완성본을 5초 간격으로 18장 뽑은 것 |
| `credits.md` | 인용, 음악, 효과음의 출처와 조건 |

## 대본에서 영상으로

1. 대본의 비트 9개를 장면 9개로 묶었습니다. 카드의 시작과 끝 시각은 대본과 같습니다.
2. 장면마다 그릴 대상, 대상의 앞뒤 상태, 문장과 대상의 대응을 프로젝트 파일에 적었습니다(Motion Art Director의 대상 우선 계약).
3. 그림은 모두 코드로 그린 SVG입니다. 어둑한 복도, 문, 옆모습 사람, 위에서 본 평면도, 문 아홉 개, 스위치와 화구.
4. 정지 화면을 뽑아 보며 고친 뒤 1080p로 렌더하고, 도구의 검수를 돌렸습니다.

## 두 판

처음 만든 판은 문장을 화면 아래 띠에 깔았고 음악을 도구의 합성음으로 만들었습니다. 그 판을 보고 받은 의견은 둘이었습니다. 자막이 아래에 떠서 집중이 안 된다, 그리고 공개 음원을 찾아 쓰는 절차가 있는데 왜 합성음인가. 둘 다 제작 쪽의 잘못이었습니다. 이 폴더의 영상은 고친 둘째 판입니다.

| 항목 | 첫 판 | 둘째 판 (이 영상) |
|---|---|---|
| 문장의 자리 | 화면 아래 어두운 띠, 왼쪽 정렬 | 모든 카드가 화면 한가운데 같은 자리, 가운데 정렬, 띠 없음 |
| 문장의 모양 | 굵은 글씨, 강조는 빨강 | 가는 흰 글씨, 강조는 굵기 한 단계. 인용은 같은 자리에 명조 |
| 화면 | 밝은 복도, 그림이 화면 가득 | 어둑한 복도. 그림은 문장 자리를 비우고 좌우 3분의 1이나 위아래에 |
| 음악 | 합성음 | 공개 음원 세 곡을 찾아 세 판을 만들고, 들어 보고 한 곡을 골랐습니다 |
| 효과음 | 전부 합성음 | 발소리와 문이 걸리는 소리는 녹음(Mixkit), 짧은 표시음만 합성음 |

이 경험이 스킬의 규칙이 되었습니다: 화면 문장의 자리와 모양(`references/02` 13절), 음악은 공개 녹음에서 고른다(`references/04` 7절, `meta.music_brief`).

## 대본과 다르게 만든 곳

| 카드 | 대본의 제안 | 영상 | 까닭 |
|---|---|---|---|
| c01 | 옆모습 전신, 스티커는 손 그림자에 가려 읽히지 않는다 | 문은 정면, 사람은 옆모습, 스티커는 아래팔 밑 | 옆모습으로는 문 앞면의 스티커가 보이지 않습니다 |
| c02 | (앞 장면 계속) 지나온 문 둘이 보인다 | 화면이 물러난다 | 앞 카드가 손잡이로 다가간 채 끝나 지나온 문이 화면 밖이었습니다 |
| c05 | 평면도와 반대 방향 화살표 | 사람 머리와 어깨, 스티커 표시를 더하고 색을 정했다(노랑은 생김새, 빨강은 글자) | 어느 화살표가 무엇인지 가르려면 표시가 필요했습니다 |
| c06 | 같은 사람의 뒷모습 | 옆모습 | 뒤에서는 미는 것과 당기는 것이 구별되지 않습니다 |
| c14 | 엉킨 선, 수도꼭지, 화구와 손잡이 | 스위치를 눌러 엇갈린 전등이 켜지고, 손잡이 하나에 화구 둘이 번갈아 깜박인다 | 무엇이 헷갈리는지 동작으로 보였습니다 |

문장은 대본 그대로입니다. 이 차이들은 `script-revised.json`에 되돌려 적었고, 같은 일이 다시 생기지 않도록 스킬에 제작 인계 칸(`meta.cast`, `visual.frame`, `visual.text_in_picture`, `visual.events`)과 검수를 더했습니다.

## 남은 것

- c08은 4초에 17자입니다. 제작 읽기 하한(글자 수/7 + 2초)에 0.4초 모자랍니다. 고친 대본에서는 늘렸습니다.
- 도해(평면도, 문 아홉 개)는 문장 자리를 비우느라 작아졌습니다. 평면도의 스티커 표시 글자가 작습니다.
- 장면 7에서 문장이 초록 문의 테두리 선 위에 걸칩니다.
- 대본의 "밝은 쪽으로 옮겨 간다"는 음악 지시는 기성 음원으로 맞출 수 없어 뺐습니다.
