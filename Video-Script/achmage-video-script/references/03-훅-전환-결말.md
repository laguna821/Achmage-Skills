# 훅, 전환, 결말

카드를 쓸 때 아래 유형표에서 고른다. 예문은 구조를 보여 주려고 새로 쓴 것이다. 그대로 가져다 쓰지 않는다.

## 1. 훅

### 1-1. 감춤형 (A1, A3)

첫 카드에서 주제어와 이름을 말하지 않는다. 사람이나 감각에서 시작한다.

| 유형 | 방법 | 예 |
|---|---|---|
| 일상을 비유로 바꿔 부르기 | 흔한 경험에 다른 이름을 붙이고 정체는 다음 장면이 푼다 | "오늘도 줄을 섰다 / 번호표도 없이" |
| 은유 장면 + 목적어에서 끊기 | 장면이 은유를 맡고 문장은 미완성으로 멈춘다 | "사람들은 모른다" (물 위의 백조, 물속의 발) |
| 회상으로 통념 비틀기 | "~이 없었을 때"로 시작해 지금을 낯설게 한다 | "길을 물어볼 사람이 필요했던 시절" |
| 화자 없는 논쟁 | 따옴표 두세 개를 맞세운다. 시대와 화자는 밝히지 않는다 | "우산은 원래 잃어버리는 물건이야" / "아니, 빼앗기는 물건이지" |
| 좁혀 들어가기 | 문장 없이 넓은 그림에서 시작해 한 장에 하나씩 좁힌다 | (지도) → "도시의 서쪽 끝" → "간판 없는 가게" |
| 옛이야기 첫머리 | 때, 곳, 주인공, 소원을 차례로 | "때는 1854년 / 런던 소호의 우물가" |
| 이름을 숨긴 일화 | 유명해지기 전, 본업이 아닌 일화로 연다 | "입학시험에 두 번 떨어진 소년" |
| 1인칭 재연 | 설명 없이 한 사람의 속말로 들어간다 | "또 닫힘 버튼을 눌렀다 / 세 번째다" |
| 수식어 먼저, 주어 나중 | 수식절을 한 장, 주어를 다음 장에 | "하루에 백 번을 눌러도 닳지 않는" → "어떤 버튼" |

공통 규칙

- 훅은 카드 3~6장, 25~40초. 제목은 그 뒤에 온다.
- **훅의 마지막 카드는 예고형 명사구나 가설로 멈춘다.** "그날 선생님이 건넨 말", "어쩌면 버튼 때문이었는지도 모른다". 답은 편집 문장이 아니라 제목 뒤의 실험, 인용, 화면 속 글자가 준다.
- 훅 안에 구체적인 숫자나 사물 하나를 둔다.
- 마지막 한 줄이 되받을 낱말이나 장면을 여기 심는다.

### 1-2. 차가운 사실형 (A2)

날짜, 수치, 사전 정의로 시작한다. 질문이나 감정 호소로 열지 않는다. 진짜 훅은 27~57초에 나오는 제목이고, 제목은 앞의 사실과 어긋나게 놓는다.

### 1-3. 리드형 (C, D1)

- 결과나 발견을 첫 문장에 말하고 이름은 그 뒤에 준다. 결말을 숨기지 않고 "어떻게"에 궁금증을 건다.
- 리드 한 문장을 카드 두 장에 나눈다. 한 장에는 사건, 다른 장에는 그 사건과 긴장을 이루는 조건.

```
[카드 1] 이 다리는 개통 첫날
[카드 2] 한 사람도 건너지 못했다
```

- 낯선 물건은 하는 일을 먼저 말하고 정식 이름은 다음 카드로 미룬다.

### 1-4. 정점 먼저형 (B)

정체를 숨긴 주어("누군가", "한 남성", "검은 물체")로 동작만 현재형으로 적는다. 15~25초에 가장 센 장면을 보여 주고, 그 뒤에 날짜와 장소 표기로 되감는다.

### 1-5. 그림과 질문형 (D2)

문장 없이 대상을 보여 준 뒤 질문 한 줄. 답은 풀어 쓴 정의 한 문장으로 주고, 이름은 그 뒤 이름 카드로 준다. 개념의 이름을 `meta.withhold`에 적어 두면 이름 카드 전에 새지 않는지 검수가 본다.

## 2. 무엇을 미루는가

| 미루는 것 | 언제 주나 | 어떻게 |
|---|---|---|
| 주제어 | 제목 이후 | |
| 개념과 인물의 이름 | 사례와 근거를 본 뒤. 5분이면 40~60% 지점 | 예고 카드 한 장("이 현상에 붙은 이름") + 이름만 크게 띄우는 카드 한 장 |
| 개념의 정의 | 이름보다 **먼저** | 풀어 쓴 정의를 읽히고, 이름은 그 뒤 빈 화면에 혼자. 이름이 나올 때 시청자는 이미 뜻을 안다 |
| 결과 수치 | 방법을 본 뒤 | 방법 2~3장 → 결과 1~2장 → 소결론 1장 |
| 규모를 묶는 수치 | 사람 이야기가 선 뒤, 결산 대목 | |
| 화자 | 발언을 먼저 읽힌 뒤 | 호칭은 익명 → 범주 → 실명으로 좁힌다 |
| 편집자의 판단 | 끝까지 미루거나 인용에 넘긴다 | |

해설형은 예외로, 근거 자료의 규모를 1분대에 먼저 낸다. 자료의 신뢰부터 세워야 하기 때문이다.

## 3. 전환 장치

한 편에 꺾임을 두 번 넣는다. 첫 꺾임은 통념을 흔들고, 둘째 꺾임은 **방금 낸 결론의 전제**를 흔든다.

| 장치 | 방법 | 예 |
|---|---|---|
| 접속어 단독 카드 | 검은 화면이나 흐린 화면에 한 단어 | "그런데" |
| 단정 뒤 부정 | 길을 하나로 좁혀 놓고 다음 카드에서 그 길을 버린다 | "길은 지름길 하나뿐" → "그러나 그는 돌아가는 길을 골랐다" |
| 수량 한정으로 전제 흔들기 | 방금 낸 결론이 좁은 조건에서만 참임을 드러낸다 | "그런데 이 조사에 답한 사람은 / 단 한 마을" |
| 통념을 따옴표로 세우고 반문 | | "'일찍 일어나는 새가 벌레를 잡는다' / 정말 그럴까" |
| 시청자의 반론 대신 말하기 | 따옴표 한 장으로 말하고 바로 넘어간다 | "그래도 손해 보는 건 싫은데" |
| 낱말 뒤집기 | 낱말 하나의 방향을 바꿔 논지를 압축한다 | "낭비" → "여유" |
| 개념 명명 | 이름 붙이는 순간이 단락의 매듭 | |
| 수치 대조 | 기대값과 실제값을 나란히 | "3분이 아니라 / 30분" |
| 시간 점프 | 날짜만 먼저, 사건 이름은 다음 카드 | "그리고 / 1945년 8월" |
| 범위 이동 | 먼 사례에서 "우리"로 | |
| 같은 틀 깨기 | 세 번 되풀이한 문형의 넷째에서 핵심어를 바꾼다 | |
| 그림이 먼저 꺾기 | 도해나 장면이 답을 먼저 보여 주고 문장이 뒤따른다 | (빈 교집합) → "한 명도 없었다" |
| 침묵 | 문장을 거두고 장면과 소리만 | |

## 4. 결말

### 4-1. 순서

1. **정리 카드** 1~3장: 쓸모, 결산 수치, 묶는 낱말. 여기까지가 편집자의 말이다.
2. **뜸**: 문장 없는 장면 3~6초.
3. **마지막 한 줄**: 아래 넷 가운데 하나. 정리보다 한 걸음 더 나가거나 방향을 튼다.

결말 구간은 카드 2~4장, 20~30초. 길게 맺지 않는다.

### 4-2. 마지막 한 줄의 유형 (`meta.ending.type`)

| 유형 | 언제 | 예 |
|---|---|---|
| `질문` | 탐구형, 답이 열려 있을 때 | "당신은 오늘 몇 번 눌렀는가" |
| `인용` | 당사자나 사료의 말이 있을 때 | 주인공의 한마디, 사료 한 줄 |
| `사실` | 서사형, 후일담이 반전일 때 | "그 다리는 지금 없다" |
| `선언` | 처방형. 1인칭이나 2인칭 한 줄 | "나는 오늘 한 정거장 먼저 내린다" |

### 4-3. 되받기

- 마지막 한 줄은 훅의 비유, 낱말, 장면, 제목 문구 가운데 하나를 되받는다. 새 정보를 주지 않는다. 같은 말이 그 사이에 쌓인 사실 때문에 다른 무게가 된다.
- 낱말을 되받을 때는 시제나 한정어만 바꾼다. 장면을 되받을 때는 첫 장면을 문장 없이 다시 보여 준다.
- 되받는 낱말은 훅에만 나온 말이거나 두 어절 이상의 구로 고른다("또 틀렸다", "종이 한 장"). 본문 곳곳에 나오는 흔한 낱말은 되받아도 되받은 줄 모른다.
- 개념 설명형(`D2`)의 마지막 한 줄은 대개 `질문`이다. 훅의 질문에서 주어나 시제만 바꿔, 이제 답을 아는 시청자에게 다시 묻는다.
- 서사형에서 후일담으로 뒤집을 때만 되받기를 생략할 수 있다.

### 4-4. 쓰지 않는 결말

- 요약("지금까지 ~을 알아보았다")
- 당부와 당위("~해야 한다", "~합시다", "기억하자")
- 편집자의 감상("참 놀라운 일이다")
- 미해결 선언 뒤에 덧붙이는 부가 사실

`B` 갈래는 의견 대신 "아직 아닌 것", "알려지지 않은 것"을 사실로 적는다. `D1` 갈래는 주어를 "우리"로, 시제를 미래로 바꾼다.

## 5. 근거

- 훅 유형: 지식채널e 13편에서 9가지, 역사채널e 5편에서 4가지, AJ+와 NowThis와 Brut의 리드, 엠빅뉴스의 정점 먼저.
- 정의 먼저 이름 나중: 뉴스타파 '다 네 잘못이다'.
- 결말: 지식채널e 13편 가운데 편집자의 평가나 교훈으로 끝나는 편이 없다. 12편이 훅이나 제목을 되받는다. 역사채널e 5편은 질문이나 행동 촉구 없이 단정문이나 인용으로 닫는다.
