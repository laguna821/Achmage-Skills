# 검수

검수는 두 겹이다. 스크립트가 세는 것(자동)과 사람이 읽어야 아는 것(수동).

## 1. 자동 검수 (`scripts/build_sheet.py`)

결과는 `통과`, `주의`, `실패` 셋 가운데 하나다. `실패`는 반드시 고친다. `주의`는 읽고 판단한다.

### 분량과 속도

| 코드 | 보는 것 | 주의 | 실패 |
|---|---|---|---|
| `card-length` | 편집 카드의 글자 수(공백과 문장부호 제외) | 36자 이상 | 41자 이상 |
| `card-length` (인용) | 인용 카드의 글자 수 | 51자 이상 | 71자 이상 |
| `card-lines` | 카드의 줄 수 | | 편집 4줄 이상, 인용 5줄 이상 |
| `line-length` | 한 줄의 글자 수 | 19자 이상 | 25자 이상 |
| `read-speed` | (카드의 글자 수 + 구석 표기 글자 수의 절반) ÷ 노출 초 | 초당 3.5자 초과 | 초당 5자 초과 |
| `screen-load` | 편집, 인용, 이름, 제목, 표기, 구석 표기를 모두 합친 글자 수 ÷ 전체 초 | 초당 4자 초과 | |
| `card-duration` | 카드 노출 시간 | 2초 미만(접속어 단독 제외), 12초 초과 | |
| `total-density` | 편집 문장 총 글자 수 ÷ 전체 초 | 초당 3.4자 초과 | 초당 4.2자 초과 |
| `thin-density` | 같은 값의 하한 | `A1`·`A2`·`A3`는 초당 2.0자 미만(5분에 600자), `C`·`L`은 1.6자 미만, `D1`·`D2`는 1.5자 미만 | |
| `thin-cards` | 편집 카드의 평균 글자 수 | 15자 미만. 한 줄짜리 조각 카드가 많다는 뜻 | |
| `label-length`, `label-speed` | 표기 카드 | 34자 초과, 초당 6자 초과 | |
| `title-length` | 제목·이름 카드 | 16자 초과 | |
| `overlay-length` | 구석 표기(`label`) | 30자 초과 | |
| `duration` | 전체 길이와 목표 길이의 차 | 10% 초과 | 25% 초과 |
| `timing` | 카드의 시각이 순서대로 이어지는가 | 0.5초 넘는 빈틈 | 겹침 |
| `sentence-count` | `D1`, `D2` 갈래의 편집 문장 수(다음 카드로 넘기지 않는 카드를 문장 하나로 센다) | 9개 이상 | 12개 이상 |

영어 대본(`meta.lang: "en"`)은 글자 대신 단어로 센다. 기준값은 `02` 11-2절의 표에 모아 두었다: 카드 13단어 주의와 17단어 실패, 한 줄 7단어 주의, 초당 2.5단어 주의, 전체 밀도 초당 1.6단어 주의, 화면 글자 전체 초당 2.0단어, 인용 20단어, 표기 카드 16단어, 이름·제목 8단어, 구석 표기 40자, 제작 읽기 하한 단어 수/3 + 2초. 성긴 대본, 잘게 쪼갠 카드, 줄 길이, 제작 읽기 하한, 출처 표기 시간, 시간 표지도 영어 대본에서 돈다. 영어에서는 마침표 검수가 돌지 않고 당부 표현은 여섯 구절만 잡는다.

`B` 갈래는 카드가 짧고 많은 것이 정상이므로 `card-duration`의 하한을 1.5초로 낮추고 `thin-density`, `thin-cards`를 보지 않는다.

### 구조

| 코드 | 보는 것 | 결과 |
|---|---|---|
| `title-card` | 제목 카드가 있는가. `A1`, `A3`는 20~60초, `A2`는 25~60초 사이인가 | 없으면 실패(`B`, `C`, `D1`, `D2`는 없어도 통과), 범위를 벗어나면 주의 |
| `withhold` | 감춤형 훅일 때, `meta.withhold`의 낱말이 제목 카드 전의 **화면 문장**에 나오는가. 그림 훅(`D2`)이면 첫 이름 카드 전까지를 본다. 장면 설명은 보지 않는다. 장면은 주제 대상을 보여 줘도 된다 | 나오면 실패 |
| `name-position` | `A1`, `A2`, `A3`에서 첫 이름 카드가 전체의 30~65% 지점에 있는가. 이름 카드가 있을 때만 본다(`A3`은 제목이 이름을 겸해 이름 카드가 없는 것이 보통이다) | 벗어나면 주의 |
| `second-turn` | `A1`, `A3`에서 마지막 꺾임이 전체의 50~80% 지점에 있는가(권장은 55~75%) | 벗어나면 주의 |
| `lead` | 리드형 훅일 때, `meta.lead`가 적혀 있고 첫 문장 카드가 8초 안에 나오는가 | 아니면 주의 |
| `time-markers` | `C` 갈래에서 연도, 나이, 경과 표지가 든 카드가 3장 이상인가 | 모자라면 주의 |
| `hook-close` | 감춤형 훅의 마지막 카드가 "-다."처럼 닫힌 서술로 끝나는가 | 닫혀 있으면 주의 (예고형 명사구나 가설을 권장) |
| `turns` | `turn: true` 카드의 수. `A1`, `A2`, `A3`는 2장 이상, `B`와 `C`는 1장 이상, `D1`, `D2`, `L`은 없어도 된다 | 모자라면 주의 |
| `turn-word` | 꺾임 카드의 첫 줄이 접속어로 시작하는가 | 아니면 주의 |
| `card-endings` | 편집 카드의 끝을 넘김, 명사로 멈춤, 끝맺음 셋으로 나눈 비율 | 끝맺음 70% 초과, 끝맺음 12% 미만(`A2` 제외), 넘김 15% 미만이면 주의 |
| `silence` | 무문장 카드의 수. 3분 이상이면 3곳 이상 | 모자라면 주의 |
| `pre-ending-pause` | 마지막 문장 카드 바로 앞이 무문장 카드인가. 2분 미만이면 보지 않는다 | 아니면 주의 |
| `division` | 비트의 절반 이상에 `scene`과 `text`가 적혀 있는가 | 아니면 주의 |

| 코드 | 보는 것 | 결과 |

### 결말

| 코드 | 보는 것 | 결과 |
|---|---|---|
| `ending-type` | `meta.ending.type`이 질문, 인용, 사실, 선언 가운데 하나인가 | 아니면 실패 |

### 사실과 장면

| 코드 | 보는 것 | 결과 |
|---|---|---|
| `quote-source` | 인용 카드에 `src`가 있는가. `attribution`은 이어지는 인용의 마지막 장에만 있으면 된다 | 없으면 실패 |
| `quote-form` | `quote_form`이 원문, 번역, 줄임, 번역·줄임 가운데 하나인가 | 아니면 주의 |
| `number-source` | 숫자로 쓴 수치가 든 편집 카드에 `src`가 있는가. 한글로 쓴 수("서른다섯", "이십 분")는 세지 못한다 | 없으면 주의 |
| `source-ref` | 카드가 가리키는 `src`가 `meta.sources`에 있는가 | 없으면 실패 |
| `unverified` | `note`에 "미확인"이 든 카드 | 주의로 모아 보여 준다 |
| `visual` | 모든 카드에 `visual.type`과 `visual.desc`가 있는가 | 없으면 실패 |
| `carries` | 타이포를 뺀 문장 카드 가운데 `visual.carries`가 적힌 비율 | 70% 미만 주의 |
| `stock-heavy` | `스톡`(대역 영상) 유형의 비율. 대상을 직접 찍은 영상은 찾아 쓴 것이어도 `실사`다 | 40% 초과 주의 |
| `footage-brief` | 찾아 쓰는 영상 카드에 `visual.footage`의 검색어나 다시 쓸 카드가 있는가. `footage`를 한 장이라도 쓴 대본만 본다 | 없으면 주의 |
| `footage-fallback` | 대상을 직접 찍은 영상(`실사`)을 찾아 쓰는 카드에 못 찾을 때의 대안(`fallback`)이 있는가 | 하나도 없으면 주의 |
| `source-card-time` | 참고 자료 카드(`표기`, 6단어 또는 20자 이상)가 제작 읽기 하한을 넘는가 | 못 넘으면 주의 |
| `stand-in-label` | 대역 영상 위에 연도가 든 구석 표기가 있는가 | 있으면 주의 |

카드의 끝(넘김, 명사, 끝맺음)은 마지막 글자를 보고 어림하는 것이라 틀릴 수 있다. "글자", "미만"처럼 조사로 끝나는 듯한 명사는 예외 목록으로 걸러 내지만 다 걸러 내지는 못한다. 잘못 센 카드에는 `end` 필드로 직접 적는다.

해당 사항이 없는 항목(인용이 없는 대본의 `quote-source` 등)은 "해당 없음"이라고 적혀 통과로 나온다.

`--print-cards`를 붙이면 카드를 시각 순서대로 뽑아 준다. 편집 카드마다 끝의 분류가 붙는다. 가편집 시트를 열 수 없을 때 읽기 리허설에 쓴다.

`--lint-only`는 실패와 주의, 그리고 통과한 항목의 이름을 보여 준다. 통과한 항목의 기준과 수치까지 보려면 `--verbose`를 붙인다. 자동 검수가 통과했다는 것은 "센 것 가운데 걸린 것이 없다"는 뜻일 뿐이다. 아래 수동 검수를 건너뛰지 않는다.

## 2. 수동 검수

스크립트가 볼 수 없는 것이다. 가편집 시트를 열어 놓고 차례로 확인한다.

- [ ] **중복**: 장면에 보이는 것을 문장이 다시 말하는 카드가 없는가. (가장 흔한 실패)
- [ ] **은유**: 장면이 맡은 은유를 문장이 풀어 쓰지 않았는가.
- [ ] **강조어 읽기**: 강조한 구절만 차례로 읽어도 줄거리가 서는가.
- [ ] **이름의 자리**: 개념과 이름이 사례와 근거 뒤에 나오는가. 정의가 이름보다 먼저 나오는가.
- [ ] **둘째 꺾임**: 둘째 꺾임이 방금 낸 결론의 전제를 흔드는가. 그냥 주제를 바꾸는 것은 아닌가.
- [ ] **축이 되는 사실**: `meta.axis_fact`가 실제로 대본의 한가운데에 있는가. 그 사실이 대상을 더 무겁게 만드는가.
- [ ] **마지막 한 줄**: 정리 카드보다 한 걸음 더 나가는가. 새 정보를 주지 않는가. 되받는 낱말이 "조용"처럼 본문 곳곳에 나오는 흔한 말은 아닌가.
- [ ] **편집자의 감상**: 편집 문장에 평가가 숨어 있지 않은가. 감정은 인용이 맡았는가.
- [ ] **인용의 진위**: 인용 카드의 문장이 출처에 실제로 있는가. 번역하거나 줄였다면 뜻이 바뀌지 않았는가.
- [ ] **사실의 최신성과 범위**: 현재형으로 쓴 수치("지금은 하루 ~")가 가장 최근 자료와 맞는가. 연구가 잰 것보다 넓게 말한 문장이 없는가. 대상을 밝게 맺으면서 출처에 있는 중대한 사실을 뺀 것은 아닌가.
- [ ] **가편집 읽기**: 재생으로 끝까지 한 번 읽었는가. 숨이 찬 자리, 기다려지지 않는 자리가 없는가.
- [ ] **소리 없이**: 음악 없이도 구간의 경계가 보이는가.

제작 스킬에 넘길 대본이면 아래도 본다.

- `carries`에 적은 정보가 그 카드의 시점에서 실제로 보이는가. 뒷모습, 옆모습, 위에서 본 모습 가운데 무엇이어야 보이는지 따져 본다.
- 아직 읽히면 안 되는 그림 속 글자가 화면이 다가가는 카드에 걸려 있지 않은가.
- 줄이 차례로 뜬다고 할 때 둘째 줄이 (글자 수/7 + 0.8초) 넘게 보이는가.
- 비트의 마지막 카드가 장면이 넘어가는 0.5초를 빼고도 읽히는가.
- 소리 지시 가운데 곡을 새로 지어야만 맞출 수 있는 것에 대안이 적혀 있는가.
- 화면 문장이 모든 카드에서 같은 자리(화면 한가운데), 같은 모양으로 뜨는가. 아래 자막 띠나 상자에 들어가 있지 않은가.
- 그림이 문장 자리를 비워 두었는가. 문장이 떠 있는 동안 그림이 문장보다 밝거나 바쁘지 않은가.
- 음악이 공개 음원인가. 곡마다 출처, 이용 조건, 표시 의무가 적혀 있는가.

## 3. 흔한 실패와 고치는 법

| 증상 | 까닭 | 고치는 법 |
|---|---|---|
| 첫 카드가 "오늘은 ~에 대해" | 내레이션 원고의 버릇 | 사람 하나의 처지나 사물 하나로 바꾸고 주제어를 `withhold`에 넣는다 |
| 카드마다 "-다"로 끝난다 | 문장 단위로 카드를 나눴다 | 한 문장을 2~3장으로 쪼개고 앞 카드를 연결어미에서 끊는다 |
| 읽기 속도 주의가 여럿 | 카드에 문장을 욱여넣었다 | 수식어를 장면으로 보내고, 그래도 길면 카드를 나눈다. 노출 시간만 늘려 해결하지 않는다 |
| 전체 밀도 초과 | 설명을 문장으로 다 했다 | 근거 블록 하나를 도해에 넘기거나 사례 하나를 뺀다 |
| 끝맺는 카드가 거의 없다 | 끝없이 이어지는 한 문장 | 소결론마다 "-다" 카드를 한 장 세운다 |
| 카드 평균 15자 미만 | 구절마다 카드를 나눴다 | 이웃한 두 장을 2줄 카드 한 장으로 묶는다. 한 줄 카드는 접속어, 이름, 가장 무거운 한마디에만 |
| 초당 1.5자 미만 | 사례나 근거가 한 겹뿐이다 | 근거 블록을 하나 더 넣거나 통념을 한 겹 더 성의 있게 세운다. 노출 시간을 줄여 맞추지 않는다 |
| 표기 카드가 시간을 많이 쓴다 | 날짜와 출처를 따로 띄웠다 | 문장 카드의 구석 표기(`label`)로 옮긴다 |
| 수치 주의 | 한 카드에 숫자 둘 | 두 장으로 나누거나 하나를 도해로 |
| 마지막이 당부 | 메시지를 못 믿어서 | 당부를 지우고 그 앞 카드에서 끝내 본다. 훅의 낱말을 되받는 한 줄로 바꾼다 |
| 꺾임이 한 번뿐 | 통념 뒤집기에서 끝났다 | 뒤집은 결론이 참이 아닌 조건을 찾아 둘째 꺾임으로 쓴다 |
| 이름이 0:40에 나온다 | 정의부터 하고 싶어서 | 사례를 앞으로 당기고 이름은 예고 카드 뒤로 민다 |

## 4. 주의를 그대로 둘 때

`주의`는 규칙 위반이 아니라 다시 보라는 표시다. 그대로 두기로 했으면 까닭을 `meta.review_notes`에 한 줄씩 적는다. 시트에 함께 표시된다.

예: "`card-endings` 끝맺음 72%: 논증형이라 소결론 카드가 많다", "`numbers` c17: 기대값과 실제값의 대조라 한 장에 둔다(`compare: true`로 바꿈)".
