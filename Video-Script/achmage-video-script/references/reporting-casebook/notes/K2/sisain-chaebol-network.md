# 5만4000개 기업 데이터 분석, '재벌해체론' 틀렸다 (시사IN 제602호)

- 필자 / 매체 / 날짜: 부산·이종태 기자 / 시사IN / 2019-04-01
- URL: https://www.sisain.co.kr/news/articleView.html?idxno=34251
- 유형: 본보기
- 분량(대략): 약 7,500자(문답 위주)
- 읽은 범위: 전문(공개 열람, 유료 벽 없음)
- 한 줄 요약: 부경대 산업생태계 연구팀의 기업 간 거래 네트워크 데이터로 "재벌이 한국 경제 문제의 원흉"이라는 통념을 검토하는 좌담 기사. 제목이 이미 결론("틀렸다")을 단정한다.

## 1. 질문
기업 간 거래 데이터로 볼 때 재벌 대기업은 정말 중소기업 성장을 막는 원흉인가.

## 2. 발단
글에서 보이는 바로는 기자가 연구팀의 최근 작업을 기사화한 것이라고 밝힌다. 구체적 계기는 확인 못함.

## 3. 취재와 자료
- 기자가 직접 분석한 것이 아니라 연구팀 작업(한국기업데이터의 170만여 개 기업 정보 2006~2016, 표본 5만4천여 개)을 문답으로 전한다.
- 본문에 인용된 다른 자료: 통계청 기업활동조사, 한국은행 2018년 12월 금융안정 보고서, 2017년 산업연구원 설문(전속 협력업체 200개), 공정거래위원회 조사(2만3297개), 워즈오토 2019 세계 10대 엔진 선정.

## 4. 축이 되는 사실이나 장면
"기업 46% 정도가 선도기업 거래 네트워크에 편입(협력업체), 나머지 54%가 독립기업이며 독립기업이 협력업체에 비해 규모·기술력·임금이 열악하다." 그리고 영업이익률 수치(협력업체는 불황기 4%대 초반, 호황에도 5%를 크게 넘지 않음). 위치는 앞에서 약 30%. 도입은 아이스크림과 물놀이 사고의 상관 대 인과 비유로 시작한다.

## 5. 구조
1. 도입: 아이스크림/물놀이 비유로 인과 확인의 필요성을 세운다.
2. 진보와 옹호 양 진영의 입장 요약, 연구 소개.
3. 문답: 데이터 취득, 구성(협력업체, 독립기업), 재무 추이, 원인, 수직계열화, 수소차 논쟁, 지역 산업 구조조정, 미래 산업, 노동운동.
4. 결말: 연구원의 노동운동에 대한 주문(인용)으로 끝난다.
통념(재벌 원흉론)을 먼저 세우고 데이터로 문답하는 구조지만 후반은 정책 의견으로 이동한다.

## 6. 근거를 보이는 방식
- 데이터 출처(한국기업데이터)와 표본 기간, 크기가 앞쪽 문답에서 구체적으로 나온다.
- 비교에서 조건이 어긋나는 곳: 2017년 산업연구원 설문(전속 협력업체 200개, 37%가 큰 문제)과 공정위 조사(2만3297개, 8.7%가 불만)를 나란히 놓고 개선 효과를 말한다. 두 조사의 표본, 질문이 같은지는 본문에서 밝혀지지 않는다.
- 수치 일부는 출처가 없다: "독립기업 가운데 27.5%는 정부 발주", "정부 조달 비중 평균 32.9%", 영업이익률 4%대, 5% 등은 연구팀 DB 결과로 읽히지만 본문에 명시되지 않는다.
- 익명 출처: 현대차의 전기차 판단은 "그쪽 전문가들에 따르면 ..."로 소속, 직위 없이 쓴다. 신문윤리실천요강 제5조(추상적 취재원 금지)에 비추어 이 문장은 근거가 약하다.
- 반론의 한계: 인터뷰이는 연구팀 두 명뿐이고 재벌 개혁론 쪽 연구자나 기업 쪽의 반론은 본문에 없다. 기자가 던지는 질문이 반론 역할을 한다("혹시 재벌 때문인가?", "...라고 한다").
- 연구 방법의 한계(인과 식별, 표본 5만4천개 선택 기준)는 본문에서 별도로 다뤄지지 않는다. "재벌 해체가 중소기업 발전의 방안이 될 수 없다"는 결론은 인터뷰이의 주장으로 나온다.
- 사진 캡션: ⓒ시사IN, ⓒ현대자동차 제공, ⓒ연합뉴스 표기.

## 7. 덜어낸 것
확인 못함.

## 8. 화면으로 옮길 수 있는 재료
거래 네트워크 도식은 이 페이지에서 보이지 않는다(확인 못함). 현대자동차 협력업체 협약 사진(현대자동차 제공)과 연합뉴스 사진. 연구팀 보고서가 있는지는 확인 못함.

## 9. 앞단 스킬로 가져갈 규칙
- 상관과 인과를 구분하는 쉬운 비유(아이스크림과 물놀이)로 데이터 기사의 방법 의식을 세운다.
- 제목이 결론을 단정하는 글을 근거로 삼을 때는 본문의 근거 강도를 따로 평가한다. 이 글은 연구팀 단독 해석을 담았다.
- 서로 다른 조사의 수치를 비교하는 문장은 표본과 질문이 같은지 확인한 뒤에만 쓴다. 근거: 산업연구원 대 공정위.
- 익명 전문가 문장("그쪽 전문가들에 따르면")은 근거표에서 근거 부족으로 표시한다.
- 연구 당사자만 인터뷰한 글은 반대 측 입장이 없다는 사실을 말할 수 있는 범위에 적는다.

## 10. 한계와 불확실
수치는 원 연구와 대조하지 않았다. 좌담 위주라 서술 기사와 구조가 다르다. 사진 이용 조건 확인 못함.
