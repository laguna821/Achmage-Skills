# 4억6500만년 전 삼엽충의 '마지막 식단'

- 필자 / 매체 / 날짜: 곽노필 기자 / 한겨레 미래&과학 / 등록 2023-10-10 (페이지에 수정 2024-06-29 표기)
- URL: http://auth.hani.co.kr/arti/science/science_general/1111465.html
- 유형: 본보기
- 분량(대략): 약 1,800자
- 읽은 범위: 전문
- 한 줄 요약: 삼엽충 화석 하나의 뱃속 내용물(싱크로트론 단층촬영)로 "삼엽충은 포식자인가 청소부인가"를 답하는 논문 소개 기사. 논문 제목과 DOI는 맨 끝에 붙는다.

## 1. 질문
삼엽충은 무엇을 먹고 살았나, 포식자였나.

## 2. 발단
확인 못함. 체코, 스웨덴 공동연구진의 네이처 논문 발표가 계기다.

## 3. 취재와 자료
확인 못함. 글에서 보이는 바로는 논문, 그리고 다른 매체의 보도에 실린 연구자 말(사이언스, 기즈모도)을 인용한다. 기자가 직접 인터뷰한 흔적은 본문에서 보이지 않는다.

## 4. 축이 되는 사실이나 장면
화석 소화관 속에서 나온 조개껍데기 조각(갑각류, 소라, 극피동물, 이매패류)과 그것이 포식자가 아니라 청소부임을 뜻한다는 논리. 위치는 앞에서 약 40%. 소제목 "삼엽충은 포식자 아닌 '해저 청소부'"가 통념("삼엽충은 포식자일 수 있다")을 건드린다. 다만 글은 이 점이 과학자 사이에서 논란이었다는 연구자의 말로 통념의 성격을 밝힌다.

## 5. 구조
1. 삼엽충의 위상(5억4000만년 전 출현, 2억7천만년 번성, 2만 종 이상).
2. 질문과 연구진 소개(첫 직접 증거).
3. 소제목: 삼엽충은 포식자 아닌 해저 청소부. 화석의 출처(1908년 개인 수집), 연구 아이디어(교수의 어린 시절 박물관 기억), 방법(싱크로트론 단층촬영, 1년 반), 결과.
4. 논란 정리(홉킨스 박사 인용).
5. 소제목: 화석 하나에 담긴 삼엽충의 삶. 탈피 직전, 소화관 특성, 터널 흔적.
6. 결말: "화석 하나가 ... 커다란 창을 열어젖힌 셈이다." 기자의 은유로 맺는다.
7. 맨 끝에 논문 정보(제목, 저널, 연도, DOI).

## 6. 근거를 보이는 방식
- 논문은 본문에서 "국제학술지 '네이처'"로만 언급하고, 제목과 DOI는 글 끝의 "논문 정보"에 모은다. 읽다가 바로 확인하는 구조는 아니다.
- 인용된 독립 전문가(홉킨스 박사, 미국자연사박물관)는 소속과 분야를 밝히고 "사이언스에" 한 말이라고 출처를 적는다. 기즈모도에서 한 알버그 교수의 말도 매체를 적는다. 다만 이 말들은 원 기사에서 재인용한 것이다. 한국 독자가 확인할 수 있는 링크는 본문에 없다.
- 추정과 확정을 어미로 가른다: "추정했다", "보인다", "시사한다", "해석했다", "드러났다". 가장 센 주장("삼엽충은 청소부")은 연구진의 해석으로 처리한다.
- 수치에는 연대와 개수가 붙는다(4억6500만년, 2만 종, 1년 반). 종 수와 연대의 출처는 없다.
- 사진 캡션에 출처 표기: "네이처 제공", "Jiri Svoboda"(상상도).

## 9. 앞단 스킬로 가져갈 규칙
- 논쟁이 있는 질문은 독립 전문가 한 사람의 말로 "논란이었다"는 사실부터 확인해 둔다. 근거: 홉킨스 박사 인용.
- 해석과 사실을 어미로 가른다. 연구진의 추정은 "연구진은 ~로 추정했다"로 쓴다.
- 인용한 외국 전문가 말에는 어느 매체에서 가져왔는지 적고, 원문 확인 링크를 근거표에 둔다. 이 글은 링크 없이 재인용했다.
- 작은 구체(1908년에 개인이 모은 화석, 할아버지가 좋아한 화석)가 독자를 대상으로 끌어들인다.
