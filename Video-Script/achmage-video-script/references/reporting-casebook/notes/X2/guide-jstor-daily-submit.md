# Submission Guidelines (JSTOR Daily)

- 필자 / 매체 / 날짜: JSTOR Daily 편집부 / JSTOR Daily / 날짜 확인 못함(페이지에 2027년 1월 재개 예정 편집자 주가 있어 2026년 후반 상태로 보임. 검색 결과 표기 2021-03-08은 최초 기록일로 보임)
- URL: https://daily.jstor.org/submit
- 유형: 지침
- 분량(대략): 700단어
- 읽은 범위: 전문
- 한 줄 요약: 기사 하나하나가 JSTOR의 학술 자료를 링크하고 그 자료를 독자에게 무료로 열어 준다는 구조를 요구하는 기고 안내.

## 1. 질문
JSTOR Daily는 어떤 기고를 받고 필자에게 무엇을 요구하나.

## 2. 발단
해당 없음(지침 문서).

## 3. 취재와 자료
요구 사항(문서의 말): 기사는 "informed by, links to, and provides free access to underlying scholarship"여야 한다. 피치에는 대상, 지금 중요한 이유, 클립 또는 이력, 인용할 JSTOR 학술 자료의 미리보기를 넣는다. JSTOR 도서 장은 보통 인용하지 못한다고 명시. 필자가 개인 JSTOR 계정으로 예비 조사를 하길 권장하되 필요하면 접근권을 준다. JSTOR 근거 없는 피치도 검토하나 "배정 전에 학술 자료와의 대화를 먼저 논의한다".

## 4. 축이 되는 사실이나 장면
해당 없음.

## 5. 구조
요구하는 글의 유형: 약 2,000단어 기능(feature), 읽기 목록(annotated bibliography), 주석, 교육용 에세이, 연재 칼럼, 컬렉션(JSTOR Collections, Reveal Digital) 기반 글, Path to Open 도서 기반 에세이. 기대하는 이야기: 현재 사건이나 역사적 순간의 세부를 풀거나 "뻔한 것을 뻔하지 않게" 보는 글. 보관 자료가 많아 "현재가 과거에 의해 형성되는 방식"을 보는 글이 많다고 설명.

## 6. 근거를 보이는 방식
문서가 요구하는 것: 학술 자료에 대한 링크와 무료 접근. 피하는 것: 이미 게재된 글의 재게재, 전공자용 글, "일처럼 읽히는" 글, 특보형 취재. 2개월 이상의 리드타임이 있어야 한다고 적는다. 팩트체크 절차는 이 문서에 확인 못함.

## 7. 덜어낸 것
해당 없음.

## 8. 화면으로 옮길 수 있는 재료
해당 없음. 단, 문서가 안내하는 JSTOR Collections와 Reveal Digital의 1차 자료(미국 교도소 신문 컬렉션 등)는 사료 입수처가 된다. 이용 조건은 확인 못함.

## 9. 앞단 스킬로 가져갈 규칙
1. 모든 주장에 독자가 열어 볼 수 있는 근거 한 건씩을 걸어 둔다. 근거: "links to, and provides free access to underlying scholarship".
2. 근거 자료의 종류를 구분해 기록한다(논문, 도서 장, 컬렉션 1차 자료). 도서 장은 인용 제약이 있는 종류로 따로 표시. 근거: JSTOR Book chapters 언급.
3. 글감 제안 단계에서 "지금 왜 이야기할 가치가 있는가"를 한 문장으로 적는다. 근거: 피치 요건 "why it's interesting now".
4. 보도처럼 변하는 사건이 아니라 이미 정리된 자료가 있는 주제를 우선한다. 근거: "we don't usually cover developing stories".

## 10. 한계와 불확실
고정된 편집 기준(팩트체크, 인용 방식)은 이 문서에 없다. 실제 기사의 관행은 별도 노트(jstor-zipper, jstor-velcro)에서 관찰.
