# Behind the Scenes of TED-Ed's Wildly Popular YouTube Channel for Students

- 필자 / 매체 / 날짜: Tina Nazerian / EdSurge / 2018-08-16
- URL: https://www.edsurge.com/news/2018-08-16-behind-the-scenes-of-ted-ed-s-wildly-popular-youtube-channel-for-students
- 유형: 과정(제3자 보도)
- 분량(대략): 약 900단어
- 읽은 범위: 전문
- 한 줄 요약: 교사 Kim Preshoff와 TED-Ed 프로그램 책임자 Stephanie Lo의 말로 TED-Ed 영상이 "제안 -> 개발 회의 -> 800~900단어 대본 -> 출처 확인과 팩트체크 -> 내레이터와 애니메이터" 순서로 4개월 이상 걸려 만들어진다고 보도한 글.

## 1. 질문
TED-Ed 애니메이션은 어떻게 만들어지나. 질문 선택 기준(Lo에 따르면): 학습자의 호기심을 가장 잘 일으키는 질문. 주제는 "topic-agnostic".

## 2. 발단
교육자가 주제를 제안하거나 직접 대본을 제안(pitch)한다. Preshoff는 교과에서 좋은 자료가 없을 때, 또는 사람들이 어떤 주제를 더 잘 알았으면 해서 고른다(생물다양성 정의를 모르는 사람이 많을 것 같아서 제안). 모든 제안이 채택되는 것은 아니라고 한다.

## 3. 취재와 자료
Preshoff에 따르면 대본은 교육자가 쓴다. TED-Ed는 대본이 제출되면 "자료를 어디서 얻었는지" 묻고 팩트체크를 한다고 Preshoff가 말한다.

## 4. 축이 되는 사실이나 장면
해당 없음.

## 5. 구조
Preshoff가 설명한 순서: pitch -> development meeting -> 대본 작성(800~900단어, "simple and direct", TED-Ed 가이드라인 준수) -> TED-Ed가 대본 검토와 출처 질의와 팩트체크 -> 내레이터와 애니메이터 투입 -> 애니메이션 진행 중 교육자가 부분을 보고 수정 요청. 최소 4개월 소요.

## 6. 근거를 보이는 방식
확인 못함(출처 표기 방식에 관한 설명 없음).

## 7. 덜어낸 것
해당 없음. 단, 가이드라인 중 하나로 "애니메이션이 말을 대체할 수 있게 쓴다"(예: 동물 이름을 나열하는 대신 화면에 보인다)가 소개되어 있다.

## 8. 화면으로 옮길 수 있는 재료
해당 없음.

## 9. 앞단 스킬로 가져갈 규칙
- 대본 원고를 제출받을 때 "자료를 어디서 얻었나"를 필수 질의로 묻는다. (근거: Preshoff의 서술)
- 글로 쓴 문장 중 화면이 대신할 수 있는 것은 화면에 맡기도록 원고 단계에서 표시한다. (근거: 생물다양성 예시)

## 10. 한계와 불확실
TED-Ed 직원이 한 팩트체크의 방법, 사람 수, 기준은 이 글에 없다. 교사 한 명의 경험에 기반한 제3자 보도다.
