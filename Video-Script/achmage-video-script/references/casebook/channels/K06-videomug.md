## 2. 대본의 뼈대

사건형(짬뽕, 센트럴파크, 출산)에서 공통으로 나타나는 순서.

1. 콜드 오픈 (0~15%): 사건의 정점 또는 가장 이상한 순간을 설명 없이 먼저 튼다. 누가, 왜는 숨긴다.
2. (채널 범퍼 2초. 짬뽕에서 확인)
3. 되감기 + 육하원칙 (10% 안팎): 날짜, 장소, 인물을 표기와 편집 문장 2~4장으로 준다.
4. 본편 재생 (35~45%): 같은 현장 영상을 처음부터 다시, 이번엔 발언 전체 자막과 함께. 시청자는 맥락을 알고 본다.
5. 덤 또는 후속 (15~25%): 영상에 없는 결과(해고, 개 반환), 뒷이야기(남편의 준법정신), 추가 한마디(탕수육).
6. 엔딩 카드 (5%): 편집자의 한 줄 + 로고.

변형 두 가지.

- 취재형(불법주차): 가정형 질문 → 볼거리(시연) → 문답 1 → 구호 → 수치 → "그런데?!" → 문답 2 → 사실 진술. 볼거리 2분 40초 뒤에 비판 1분 10초가 붙는다.
- 풍경형(만추): 탈것 소개(무문장) → 제목 → 장소 1 → 이동 문장 → 장소 2 → 이동 → 장소 3 → 맺음 2장. 구간마다 "지명 표기 + 조종사 한마디 + 편집 문장 한 장"이 한 세트다.

## 3. 도입부(훅)

- 유형 1, 정점 선공개: 결정적 대사와 반응을 예고편처럼 먼저 보여 준다. "모두가 / '짜장…" (짬뽕, 00:13-00:18).
- 유형 2, 원인을 숨긴 관찰 중계: 영상에 보이는 동작만 받아 적는다. "개목걸이째 / 개…..." (센트럴파크, 00:10-00:15).
- 유형 3, 가정형 질문과 즉답: 불법주차 차량이 길을 막아 소방차가 못 지나간다면? → 그냥 밀고 지나가라 (불법주차, 00:00-00:13. 번역본의 뜻).
- 풍경형은 훅이 없다. 12초 동안 헬기와 카메라만 보여 주고 제목을 띄운다(만추).
- 공통점: 첫 문장이 주제나 주장을 말하지 않는다. 화면에 지금 보이는 것을 가리키거나, 화면 속 사람의 속말을 대신 적는다("게살볶음밥?").

## 4. 정보 공개 순서와 전환 장치

- 순서: 동작 → 말 → 이름 → 규칙·배경 → 결과. 인물은 처음에 "여성", "한 사람"으로 부르고 이름은 한 박자 뒤에 준다.
- 인용 속 표현을 등호로 치환: "'헬멧을 든 아프…". 가해자의 말에 나온 호칭을 실명으로 바꿔 관점을 뒤집는다.
- 말줄임표 뒤의 인용: "그가 백인 여성에게 했다는 / 협박의 내용은..." → "개...목줄 좀 채워주세요". 앞서 키워 둔 말("살해 위협")과 실제 발언의 크기 차이가 반전이 된다.
- 예고하는 수식어: "'짜장면'으로 통일될 뻔한 그 순간". "뻔한" 한 낱말이 다음 발언을 반전으로 만든다.
- 같은 영상 두 번 틀기: 1회차는 모르고 보고, 배경 설명 뒤 2회차는 알고 본다(센트럴파크 00:00과 01:13, 짬뽕 00:03과 01:08).
- 수치 뒤의 한 낱말 반문: 308건, 353건 → "그런데?!" → 처분 실적 0건(불법주차).
- 뒤늦은 원인 공개: 감동담 끝에 "사실은 남편이 신호를 다 지켜서"(출산).

## 5. 결말 처리

- 편집자의 사담 카드: "To. 이 모 부장님께 / 저는 '게살 볶음밥' 시켜도 되나요?" (짬뽕). 첫 화면 말풍선을 회수하면서 사건을 시청자의 일상으로 옮긴다.
- 관용구 끊어 쓰기: "세상에 나쁜 개는 없다... / 문제는 언제나..." (센트럴파크). 뒷말을 시청자가 채운다.
- 여운: "계절은 겨울로 흐르고 / 자연은 이렇게 아름다운데..." (만추).
- 일반화 + 감사 인사: 우리도 누군가의 손에 받아져 세상에 왔다, 늦었지만 고맙다 (출산, 번역본의 뜻).
- 조건 단 사실 진술: 적어도 불법주차 차량에는 강제처분 의지를 보였다 (불법주차).
- 당사자 발언으로 끝: 감사 인사 인터뷰 뒤 음악 (손흥민).
- 공통점: 결말 직전에 "결과"를 사실로 먼저 알리고(해고, 포획, 첫 승), 맨 끝 한 줄만 편집자 목소리로 쓴다.

## 6. 문장 작법

- 분량: 편집 카드 1~2줄, 줄당 8~16자. 센트럴파크 평균 약 22자(2줄), 짬뽕 약 12자, 만추 약 15자. 노출 2.5~5초.
- 어미: 완결 평서문이 드물다. 세 편에서 "-다"로 끝난 편집 문장은 "남자는 체포되…" 하나였다. 주로 명사형 종결("~는 여성", "~던 에이미 쿠퍼", "~에서 해고", "~한 그 순간"), 연결어미 끊기("~하지만...", "~하자...", "~때문에", "~을 지나"), 전언체("돌려보냈다고")를 쓴다.
- 리듬: 카드 한 장이 한 구절이고, 서술어는 다음 카드나 다음 발언, 또는 영상 속 동작이 맡는다.
- 줄바꿈: 첫 줄에 조건·주체, 둘째 줄에 핵심. 둘째 줄이나 핵심 구절만 색을 바꾼다.
- 강조: 열쇠말을 정해 나올 때마다 같은 색·굵기로 표시한다(짜장면/해물짬뽕, 목줄/협박). 예능식 효과 글씨(히번득, 대롱대롱, 짝짝짝, 해맑ㅎㅎ)가 장면의 온도를 정한다.
- 인용 처리: 공식 발언은 이름표 + 흰 띠, 사적 대화는 손글씨체 + 강조선, 상대방 말은 띠 안에서 글자색만 바꾼다. 구어를 다듬지 않는다. 외국어는 번역하되 괄호 풀이를 한 번 넣는다('아프리카계 미…)).
- 수치: 적다. 날짜와 기간 정도. 취재형에서만 통계 2개가 한 구간에 몰려 나온다.
- 고유명사: 사진·이름표와 함께 한 번만 소개하고, 이후에는 성이나 이름만 쓴다. 별명 라벨("직장 상사", "눈치 100단 배우", "신스틸러")이 설명 문장을 대신한다.
- 말투: 편집자의 태도를 문장부호와 한두 낱말에 싣는다(";;", "해명(?)", "사과를 하긴 했지만...", "덕분인지").

## 7. 화면과 문장의 분업

- 장면이 맡는 것: 동작, 표정, 웃음, 풍경, 사건의 순간.
- 문장이 맡는 것: (1) 들리는 말의 받아쓰기와 번역, (2) 영상 밖 사실(이름, 날짜, 규정, 사후 결과), (3) 어디를 봐야 하는지의 지시, (4) 장면을 읽는 틀(직장 회식, 슈퍼 세이브, 정의).
- 영상이 없는 대목(사후 결과)은 같은 푸티지를 다시 깔고 문장만 전진한다(센트럴파크 01:45-02:15).
- 문장 없는 구간: 사건형에서는 2.5~5초의 표정 컷뿐이다. 풍경형(만추)에서는 전체의 절반 이상이 무문장이며, 기체 시점 컷이 장소 전환 신호로 쓰인다.
- 현장음: 발언이 곧 감정의 원천이다. 감탄과 정점은 편집 문장이 아니라 현장 발언("난 해물짬뽕", "아 여긴 한창이구나!")이 맡는다. 손흥민 영상에서는 중계 멘트가 끊기고 음악·함성만 남는 구간이 정점으로 보인다.

## 9. 대본 스킬로 가져갈 규칙

1. 사건의 정점을 맨 앞 15~25초에 먼저 보여 주고, 그 뒤에 날짜·장소·인물로 되감아라. 훅에서는 누구인지, 왜인지를 말하지 마라. (짬뽕, 센트럴파크, 출산)
2. 같은 장면을 두 번 써라. 첫 번째는 모르는 채로, 배경 설명 뒤 두 번째는 아는 채로 보게 하라. (센트럴파크, 짬뽕)
3. 편집 문장은 서술어를 끝맺지 말고 구절로 끊어라. 서술어 자리는 다음 장면의 동작이나 인물의 말이 채우게 하라. (짬뽕 "모두가 '짜장면'을 외칠 때", 센트럴파크 "~하자...")
4. 반전은 편집 문장으로 설명하지 말고, 편집 문장으로 발판만 놓은 뒤 당사자의 말로 터뜨려라. (센트럴파크 "협박의 내용은..." → "개...목줄 좀 채워주세요", 짬뽕 "통일될 뻔한 그…")
5. 인물은 화면에 보이는 대로 먼저 부르고("여성", "한 사람"), 이름은 시청자가 궁금해진 뒤에 줘라. 호칭이 바뀌는 순간을 전환점으로 써라. (센트럴파크)
6. 열쇠말 한두 개를 정해 영상 내내 같은 색으로 표시하고, 마지막 카드에서 한 번 더 회수하라. (짬뽕 짜장면/게살볶음밥, 센트럴파크 목줄, 만추 晩秋)
7. 영상이 없는 사후 정보는 한 구간에 몰아 2줄 카드 4~6장으로 처리하고, 평가는 문장부호나 낱말 하나로만 얹어라. (센트럴파크 "해명(?)", 불법주차의 수치 구간)
8. 풍경이나 볼거리가 주인공일 때는 문장을 지명과 이동 표시로 줄이고, 감상은 현장에 있던 사람의 말에 맡겨라. (만추, 불법주차 시연 구간)

## 10. 한계와 주의

- 표본 6편 가운데 화면을 본 것은 3편이다. 나머지 3편의 화면 문장 원문은 확인하지 못했다. 출산·불법주차 영상의 인용은 독일어 번역 자막에서 뜻만 옮긴 것이므로 한국어 원문으로 인용하면 안 된다.
- 음성은 어느 영상도 직접 듣지 못했다. "무내레이션" 판정은 자막 트랙 종류와 화면 구성에서 추정한 것이다. 음악의 역할은 확인하지 못했다.
- 표본 간격 2.5초라서 그보다 짧게 지나간 카드와 효과 글씨는 빠졌을 수 있다. 카드 수와 글자 수는 어림값이다.
- 표본이 조회수 상위 영상 위주로 보인다(4편이 1,200만 회 이상). 채널 평균 영상의 문법이라고 단정할 수 없다. 만추(조회수 1,777)는 별도 시리즈(SCOPE)로 문법이 다르다.
- 2017~2020년 영상이다. 현재 채널의 형식과 다를 수 있다.

## 11. 뉴스형 화면 문장 대본의 세 가지 쟁점

## (a) 이미 벌어진 사건의 현장 영상에 편집 문장을 얹어 이야기로 만드는 방식

- 재료가 먼저 있고 문장이 나중에 붙는다. 편집자가 바꿀 수 있는 것은 순서, 반복, 문장 세 가지뿐이다. 이 채널은 세 가지를 모두 쓴다.
- 순서: 시간순 영상을 "정점 → 되감기 → 전체"로 재배열한다. 뉴스 리드(결론 먼저)를 영상 문법으로 옮긴 것이다.
- 반복: 한 푸티지를 2~3회 쓴다. 센트럴파크는 통화 장면 음성이 세 번 들린다(00:28, 01:31, 02:19). 반복할 때마다 문장의 층이 달라진다(관찰 → 번역 전문 → 무자막 배경).
- 문장: 관찰자 시점의 지시문으로 시작해("다가오는 여성") 점차 영상 밖 정보를 든 해설로 옮겨 간다("이 영상이 찍힌…"). 시점이 영상 안에서 영상 밖으로 이동하는 것이 곧 이야기의 진행이다.
- 틀 씌우기: 사건에 일상의 틀(직장 회식의 메뉴 통일)이나 장르의 틀(슈퍼 세이브, 정의 구현)을 씌워, 남의 일을 시청자가 아는 이야기로 바꾼다.

## (b) 현장음·발언 자막과 편집 문장의 역할 분담

| | 현장음·발언 자막 | 편집 문장 |
|---|---|---|
| 맡는 일 | 감정, 정점, 증거, 당사자의 해석 | 맥락, 순서, 틀, 태도 |
| 위치 | 장면의 한가운데 | 장면의 앞(발판)과 뒤(정리) |
| 형태 | 완결된 구어 문장, 길어도 그대로 | 끊긴 구절, 명사형, 말줄임 |
| 표기 | 이름표 + 띠, 손글씨체 | 화면 가운데나 아래의 큰 글씨, 색 강조 |
| 시제 | 말한 그대로 | 현재형 관찰 또는 과거형 보고 |

- 편집 문장은 발언을 대신하지 않고 발언이 "들리게" 만든다. "협박의 내용은..."이 없으면 "목줄 좀 채워주세요"는 그냥 지나가는 말이다.
- 정보성 해설도 가능하면 사람 입에 맡긴다(만추의 내설악·외설악 설명, 출산의 과정 설명, 불법주차의 제도 설명). 편집 문장으로 단정하기 곤란한 비판은 기자 질문 + 취재원 답변으로 처리한다.
- 편집자가 발언을 지어내 얹는 층이 따로 있다(말풍선 "게살볶음밥?", "비싼 거..? 짜장면....이..죠..", "아하하하 미안"). 실제 발언과 서체·위치를 달리해 구분한다. 스킬에서는 이 층을 "가상 속말"로 따로 다뤄야 한다.

## (c) 지식채널e류 에세이형 대본과의 차이

(에세이형 쪽 기술은 지침의 형식 설명과 예문, 일반적으로 알려진 특성에 기댄 것이다. 이 작업에서 지식채널e 표본을 직접 보지는 않았다.)

| 항목 | 뉴스형(비디오머그) | 에세이형(지식채널e류) |
|---|---|---|
| 출발점 | 푸티지가 먼저, 문장이 따라붙음 | 주제문이 먼저, 장면을 골라 붙임 |
| 문장이 가리키는 것 | 지금 화면에 보이는 것("이 견공은", "그 순간") | 화면 없이도 성립하는 진술 |
| 문장의 자립성 | 낮음. 문장만 이어 읽으면 뜻이 끊긴다 | 높음. 문장만 읽어도 한 편의 글 |
| 주어 | 실명의 특정 인물, 특정 날짜와 장소 | 익명·보편의 누군가, 또는 개념 |
| 이야기의 동력 | 사실의 공개 순서(누구, 무엇, 결과) | 관점의 전환(통념 → 반문 → 새 의미) |
| 전환 장치 | 이름 공개, 실제 발언, 같은 영상 재생 | 개념 명명, 대조, 문헌 인용 |
| 감정의 출처 | 현장 발언과 표정 | 문장의 리듬과 여백 |
| 편집자 목소리 | 구어, 문장부호, 의성어, 농담 | 절제된 문어 |
| 결말 | 결과 보고 + 편집자의 한마디 | 질문, 여운, 주제문 |
| 무문장 구간 | 사건의 순간을 보게 하는 2~5초 | 생각할 시간을 주는 여백 |

- 가장 큰 차이는 문장의 자립성이다. 센트럴파크 영상의 편집 문장만 이어 읽으면 사건 개요는 나오지만 반전("개...목줄 좀 채워주세요")이 인용에 있어 핵심이 빠진다. 뉴스형 대본은 "편집 문장 + 발언 + 장면"을 한 줄로 세워야 완성된다.
- 접점도 있다. 출산 영상의 마지막 문장(우리도 누군가의 손에 받아져 세상에 왔다)은 사건을 보편으로 넓히는 에세이형 결말이다. 뉴스형 뼈대 위에 마지막 한 장만 에세이형으로 쓰는 혼합이 가능하다는 근거다.
