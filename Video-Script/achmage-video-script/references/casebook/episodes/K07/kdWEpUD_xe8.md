## 구조 메모

- 로그라인(이 영상이 하는 말 한 문장): 키 160cm의 탈북자가 중국에서 가장 삼엄한 교도소를 3분 만에 넘었고, 40일 뒤 총을 맞고 붙잡혔으며, 그 뒤는 아무도 말하지 않는다.
- 훅(첫 15~30초가 하는 일): 55초짜리 콜드 오픈이 사건 전체를 "누군가"라는 익명 주어로 한 번 다 보여 준다. 첫 카드는 "어두운 저녁" 넉 자다. 누구인지, 어디인지를 미루고 동작만 현재형으로 중계한 뒤 38초에 시간("단 3분"), 45초에 장소("지린 교도소"), 53초에 파장("중국이 발칵 뒤집혔다")을 차례로 푼다.
- 비트 구성:
	- 00:00-00:55 콜드 오픈. 익명 주어로 탈옥 압축본 → 수치 → 장소 → 파장
	- 00:58 범퍼
	- 01:00-01:23 재시작과 신원. 날짜·장소 → "한 남성이 탈주…" → 키와 나이(그래픽) → 이름
	- 01:25-02:10 탈옥 과정 정밀 재생. CCTV 시각 표시를 따라가며 동작 하나에 카드 하나. "이 모든 일이 벌…" 재등장
	- 02:13-02:38 탈출 완료. 목격자들, 교도소 밖 CCTV, "그리고," → "탈옥에 성공"
	- 02:43-03:20 과거. 특수부대 출신 → 누나의 탈북 → 교화노동형 → 2013년 월경 → 범죄와 선고 → 출소 뒤 북송 예정 → 형기 22개월 남기고 탈옥(동기가 여기서 밝혀짐)
	- 03:23-03:40 추적. 수사 실패 → 현상금 2800만 원에서 1억 3천만 원
	- 03:43-04:05 체포. 장소 → 총상 → 얼굴 → "탈주극이 막을 내렸다"
	- 04:08-04:15 뒷말. 당국의 발표와 침묵
- 전환점(시청자의 해석이 바뀌는 지점과 그것을 일으킨 장치):
	- 01:15-01:23 신원 공개. "이 남성은"에서 문장을 끊고 그래픽(키 160cm…)과 사진("탈북자 주현건")으로 답한다. 영웅적 탈출로 보이던 인물이 작은 체구의 탈북자로 구체화된다.
	- 02:55 "하지만 자유의 기쁨도 잠시.."로 탈북 서사가 범죄 서사로 꺾인다.
	- 03:10-03:18 수치의 대조가 동기를 만든다. "2023년 8…". 왜 굳이 지금 탈옥했는지를 문장으로 설명하지 않고 두 사실을 나란히 놓아 시청자가 추론하게 한다.
	- 03:55-04:00 체포 장면에서 통쾌한 활극이 한 사람의 얼굴로 바뀐다("눈에 초점을 잃…").
- 결말(마지막 2~3개 카드와 그 기능): "40일 간 중국을 떠들썩하게 했던 / 탈주극이 막을 내렸다"(검은 바탕, 사건의 종결 선언) → "지린시 공안국은 / 주 씨를 검거했다는 내용만 공개" → "이후 처리결과에 대해서는 언급하지 않았다". 마지막 카드는 사실 진술이지만 "않았다"로 끝나 빈자리를 남긴다. 편집자의 의견이나 질문 없이, 알려지지 않은 것을 알려지지 않았다고 적는 것으로 여운을 만든다.
- 문장 작법:
	- 카드당 1줄이 기본, 길어지면 2줄. 줄당 4~20자, 평균 14자 안팎. 한 문장을 3~5장에 걸쳐 잇는다. 예: "순식간에 지붕…". 각 카드는 연결어미나 조사("~더니", "~을", "~에도", "~자", "~은")로 끝나 다음 카드를 요구한다.
	- 시제가 구간을 가른다. 탈옥 장면은 현재형("기어오른다", "시도한다", "뜯어 낸다", "쳐다본다"), 과거사와 후속은 과거형("들어갔다", "체포됐다", "막을 내렸다", "언급하지 않았다").
	- 명사형 종결을 마디 끝에 쓴다("담장을 넘는 데 성공", "탈옥에 성공", "1억 3천만 원…").
	- 수치가 많고 전부 대비나 한계를 만드는 데 쓰인다(3분, 160cm, 39세, 9년, 11년 3개월, 1만 6천 위안, 22개월, 한 달, 2800만 원에서 1억 3천만 원, 40일).
	- 주어의 호칭이 정보 공개 단계에 맞춰 바뀐다. 누군가 → 한 남성 → 이 남성 → 탈북자 주현건 → 주현건 → 주 씨.
	- 접속어를 독립 카드로 세운다("그리고,", "잠시 뒤"). 한 박자 쉬는 용도다.
	- 강조는 카드마다 한두 구절에 색(파랑, 주황, 빨강)을 넣는 방식. 인용은 "그를 봤다" 한 번뿐이고 실제 발언이 아니라 소문의 내용이다.
- 화면과 문장의 분업: 재료가 CCTV 두세 개와 체포 영상 한 개뿐이라 같은 장면을 세 번 돌려 쓴다(예고, 정밀 재생, 과거사의 바탕 그림). 화면이 못 하는 일을 문장과 그래픽이 맡는다. (1) 원경이라 안 보이는 것을 원형 조명, 지붕 윤곽선, 시각 표시의 빨간 동그라미로 짚고, (2) 영상에 없는 과거사와 추적 과정은 문장만으로 전하며, (3) 문장을 비운 5초 구간(철조망을 뜯는 순간, 담을 넘는 순간)에서 동작을 보게 한다.
- 수량(대략): 편집 문장 카드 약 47장, 표기 3장, 인용 0장. 카드당 평균 약 15자, 카드 평균 노출 약 5초(대부분 표본 2개에 걸쳐 보임). 화면 문장 전체 약 720자.
