## 구조 메모

- 로그라인(이 영상이 하는 말 한 문장): 윤봉길이 던진 것은 물통 폭탄이었고, 끝내 던지지 않은 도시락 폭탄은 그가 자기 몫으로 남겨 둔 마지막 무기, 곧 목숨이었다.
- 훅(첫 15~30초가 하는 일): 분 단위 시각(1932년 4월 29일 오전 11시 50분)과 당시 신문 문장 두 건으로 "도시락 폭탄을 던진 조선 청년"이라는 통념을 사료로 먼저 세운다. 그 통념을 편집 문장 한 장으로 요약한 직후 "그러나 / 밝혀진 진실", "그러나 / 잇따른 증언"을 띄우고, 통념을 정면으로 부정하는 문장을 제목으로 쓴다. 첫 1분 안에 세우고 부수기가 끝난다.
- 비트 구성:
	- 00:00-00:36 통념 세우기: 시각 → 신문 인용 2건 → 요약("도시락 폭탄을…")
	- 00:39-01:12 뒤집기 예고와 제목: 최근 기사 종이 → "그러나" 2회 → 부정문 → 제목
	- 01:15-02:15 사건 재구성: 소문(구어체 2장) → 한 사내 → 연회장 → 일본 국가 → "그 순간" 폭탄 → 사상자
	- 02:18-02:51 축이 되는 사실: 폭탄은 "두 개". 도시락 폭탄(체포 시 소지)과 물통(이미 던짐)
	- 02:54-03:21 분류: 물통 = 저격용, 도시락 = 예비용, 자결용
	- 03:24-03:42 "그러나": 도시락… → 총살형, 24세
	- 03:45-04:06 제목 문장 반복 → "도시락 폭탄은"으로 시작하는 뜻풀이 세 번
	- 04:09-04:30 본인이 남긴 말 인용(한문, 독음, 풀이)
	- 04:33-04:49 제작진, 견해가 갈린다는 고지문, 참고문헌
- 전환점(시청자의 해석이 바뀌는 지점과 그것을 일으킨 장치):
	- 00:42-00:57 "그러나" 뒤에 오는 부정문. 누구나 아는 문장의 서술어만 뒤집는다(던진 → 던지지 않았다).
	- 02:21 "두 개". 수량 하나를 따로 큰 글씨로 띄워, 부정문의 수수께끼(그럼 뭘 던졌나)를 푼다.
	- 03:12 같은 자리의 낱말 교체("예비용" → "자결용"). 도구 분류였던 정보가 죽음을 각오했다는 뜻으로 바뀐다.
	- 03:24 "그러나 / 도시락…". 던지지 않은 것이 아니라 던지지(쓰지) 못한 것임이 드러난다.
- 결말(마지막 2~3개 카드와 그 기능): 제목 문장을 다시 한 번 적고(03:45), 주어를 고정한 세 문장으로 사실을 의미로 바꾼다: "도시락 폭탄은 / 저격수의 마지막 무기요" → "투사의 자존심이자" → "그의 목숨이었다". 이어 본인의 말 "丈夫出家生不還"을 인용해 "살아서 돌아오지 않는다"는 각오와 자결용 폭탄을 겹쳐 놓는다. 마지막에 작은 글씨로 사진의 진위와 폭탄 용도에 견해가 갈린다는 사실을 밝혀, 단정적인 제목의 책임을 따로 진다.
- 문장 작법:
	- 다섯 편 중 문장이 가장 짧다. 카드당 1~2줄, 한 줄 6~15자. 명사형 종결이 대부분이다: "상하이에 떠도…", "한 사내", "일본 국가", "경축대로 날아…", "두 개", "체포된 윤봉길".
	- 평서 "-다" 종결은 고비에만 쓴다: "모습을 드러냈다", "24세였다", "던지지 않았다", "목숨이었다".
	- 소문은 전언 구어체 "-대"로 옮겨 사람들 입말처럼 들리게 한다("누구나 참석할…").
	- 인물을 처음에는 이름 없이 "한 사내", "그 사내"로 부르다가 폭탄 설명에서 "윤봉길"로 돌아온다.
	- 라벨식 카드: "물통 폭탄 저격…". 조사 없이 명사 둘을 나란히 놓고 뒤쪽만 굵게 한다.
	- 느낌표를 쓴다("두 가지 폭탄! / 두…!"). 표본 다섯 편 중 유일하다.
	- 수치는 시각(11시 50분), 사상자 수(외 1인, 외 3인), 개수(두 개), 날짜(12월 19일), 나이(24세).
	- 글꼴은 전체가 명조·붓글씨풍이고, 신문 인용에는 큰따옴표를 쓴다. 화면 속 기사 제목(최근 보도)은 자막으로 다시 쓰지 않고 종이째 보여 준다.
- 화면과 문장의 분업: 물건(물통, 도시락 꾸러미)의 생김새는 화면이, 용도와 개수는 문장이 맡는다. 도시락 꾸러미는 처음엔 흰 실루엣으로만 보이다가 분류 대목에서 실물 사진으로 채워진다. 도입부의 체포 사진과 기사 종이가 결말 직전에 다시 나와 같은 사진을 다른 뜻으로 읽게 한다. 폭발은 문장 없이 흰 섬광으로만 처리한다(02:18, 02:51).
