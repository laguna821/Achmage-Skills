# 대본 데이터 규격

대본은 JSON 한 파일이다. UTF-8로 저장한다. `scripts/build_sheet.py`가 이 파일을 읽어 검수하고 가편집 시트를 만든다.

## 1. 전체 모양

```json
{
  "meta": { ... },
  "beats": [ ... ],
  "cards": [ ... ]
}
```

## 2. `meta`

| 필드 | 필수 | 내용 |
|---|---|---|
| `title` | 예 | 영상 제목(게시용). 훅 구절과 설명 구절로 |
| `screen_title` | | 화면 안 제목 카드의 문구. 게시용 제목보다 짧게 |
| `lang` | 예 | `"ko"` 또는 `"en"` |
| `family` | 예 | `A1`, `A2`, `A3`, `B`, `C`, `D1`, `D2`, `L` |
| `family_reason` | 예 | 이 갈래를 고른 까닭 한 줄 |
| `target_seconds` | 예 | 목표 길이(초) |
| `hook_mode` | 예 | `"감춤"`, `"리드"`, `"사실"`, `"정점"`, `"그림"` |
| `lead` | 리드형이면 예 | 첫 문장에 말할 결과 한 줄 |
| `logline` | 예 | 이 영상이 하는 말 한 문장 |
| `audience_belief` | 예 | 시청자가 이미 믿는 것. 없으면 `"없음"` |
| `axis_fact` | 예 | 축이 되는 사실 하나 |
| `withhold` | 감춤형이면 예 | 제목 카드 전까지 쓰지 않을 낱말 목록. 그림 훅(`D2`)이면 이름 카드 전까지 쓰지 않을 개념의 이름 |
| `ending` | 예 | `{ "type": "질문|인용|사실|선언", "callback": "되받는 낱말", "callback_kind": "낱말|장면|없음" }` |
| `materials` | 예 | 쓸 수 있는 화면 재료 |
| `sources` | 예 | `[{ "id": "S1", "label": "저자, 제목, 연도", "url": "...", "checked": "이 출처에서 확인한 내용 한 줄", "status": "직접 확인 / 브리프에 기댐 / 주소가 열리지 않음" }]` |
| `cast` | | 되풀이되는 대상 목록. `[{ "id": "문", "look": "세로 막대 손잡이가 달린 유리문. 경첩은 오른쪽", "fixed": "스티커는 손잡이를 쥔 팔에 가려지는 자리" }]`. 같은 대상이 세 번 넘게 나오면 적는다 |
| `visual_code` | | 색과 기호의 뜻. `[{ "sign": "노란 화살표", "means": "생김새가 부르는 동작" }]`. 도해가 두 장 넘으면 적는다 |
| `type_style` | | 화면 문장의 자리와 모양. `{ "pos": "가운데", "face": "가는 흰 고딕, 인용은 명조", "size": "화면 높이의 5%", "em": "굵기 한 단계", "ground": "어두운 화면" }`. 적지 않으면 카드 규격 13절의 기본값 |
| `music_brief` | | 음악을 고를 기준. `{ "mood": "조용한 호기심", "instruments": "피아노 독주", "tempo": "느림(60~80bpm)", "avoid": "드럼, 노래, 크게 부푸는 전개", "in": "c04", "pause": "c09 앞 1.5초", "out": "c15", "end": "곡의 끝을 마지막 한 줄에 맞춘다" }` |
| `review_notes` | | 그대로 둔 주의와 그 까닭 목록 |
| `assumptions` | | 브리프에 없어 스스로 정한 것 목록 |

## 3. `beats`

```json
{
  "id": "b1", "name": "훅",
  "job": "버튼을 거듭 누르는 손으로 조급함을 보여 준다",
  "scene": "어디서 무엇을 누르는지, 몇 번째인지 보이는 손",
  "text": "누르는 사람의 속말과 횟수"
}
```

| 필드 | 필수 | 내용 |
|---|---|---|
| `name` | 예 | 비트 시트의 이름 |
| `job` | 예 | 이 비트가 하는 일 한 줄 (작업 순서 4단계) |
| `scene` | 예 | 이 비트에서 **장면이 말할 것** (5단계) |
| `text` | 예 | 이 비트에서 **문장이 말할 것**. 찍을 수 없는 것만 (5단계) |

비트의 시각은 따로 적지 않는다. 속한 카드의 시각에서 계산된다.

## 4. `cards`

카드는 화면에 뜨는 순서대로 적는다. 문장 없는 구간도 카드다.

| 필드 | 필수 | 내용 |
|---|---|---|
| `id` | 예 | `"c01"`부터 차례로 |
| `beat` | 예 | 속한 비트의 `id` |
| `t` | | 시작 시각(초). 적지 않으면 앞 카드들의 `d`를 더해 계산한다. 적는다면 앞 카드의 `t + d`와 같아야 한다 |
| `d` | 예 | 노출 시간(초) |
| `kind` | 예 | `"편집"`, `"인용"`, `"표기"`, `"제목"`, `"이름"`, `"무문장"` |
| `lines` | 예 | 줄의 배열. 무문장이면 `[]` |
| `em` | | 강조할 구절 하나. 반드시 `lines` 안에 그대로 있는 글자 |
| `turn` | | 꺾임 카드이면 `true` |
| `compare` | | 수치 둘을 일부러 맞세운 카드이면 `true` |
| `voice` | | `"서사"`(기본), `"독백"`, `"말걸기"`, `"인용"` |
| `pos` | | 글자 위치: `"가운데"`(기본), `"아래"`, `"왼쪽"`, `"오른쪽"`. 기본값을 쓰고 한 편 안에서 바꾸지 않는다. 제작 스킬은 이 값을 그대로 따른다 (카드 규격 13절) |
| `visual` | 예 | `{ "type": "...", "desc": "...", "carries": "...", "motion": "...", "callback": true }`. 제작에 넘길 대본이면 아래 네 필드를 더 쓸 수 있다 |
| `visual.frame` | | 이 카드가 끝날 때의 화면 범위: `"전경"`, `"중간"`, `"근접"`. 화면 범위가 바뀌는 카드에 적는다 |
| `visual.text_in_picture` | | 그림 속에 실제로 적힐 글자의 배열. `["미세요"]` |
| `visual.legible` | | 그림 속 글자가 아직 읽히면 안 되는 카드이면 `false` |
| `visual.events` | | 이 카드에서 일어나는 사건의 수. 2.5초에 하나가 기준 |
| `visual.footage` | | 찾아 쓰는 영상의 조건. `{ "search": ["espresso pour dark", "espresso extraction close up"], "must": "어두운 배경, 읽히는 글자 없음", "min_len": 12, "stand_in": false }`. 앞 카드의 클립을 다시 쓰면 `{ "reuse": "c01" }`. 못 찾을 때의 대안은 `fallback`. 찾은 뒤에는 `source`에 주소와 라이선스, 기록물이면 원본의 크기 |
| `visual.overlay` | | 영상 위에 겹쳐 그릴 그림. "닦인 길 위에 흰 선, 흙길 위에 호박색 선" |
| `sound` | | 소리 큐. 구간이 바뀌는 곳에만 |
| `label` | | **구석 표기**. 이 카드와 함께 화면 구석에 뜨는 작은 글씨: 날짜, 장소, 이름과 직함, 출처, 용어 풀이. 30자 이내 |
| `src` | 인용이면 예 | `meta.sources`의 `id`. 여럿이면 배열 `["S1", "S3"]` |
| `attribution` | 인용이면 예 | 화자와 자격, 또는 문헌과 날짜 |
| `quote_form` | | 인용의 꼴: `"원문"`, `"번역"`, `"줄임"`, `"번역·줄임"` |
| `end` | | 카드의 끝을 검수가 잘못 셀 때 직접 적는다: `"넘김"`, `"명사"`, `"끝맺음"` |
| `original` | | 번역하거나 줄인 인용의 원문 |
| `note` | | 화면에 뜨지 않는 제작 메모: "미확인" 표시, 계산 근거, 제작 지시 |

`kind`의 뜻

- `편집`: 편집자가 이야기를 끌려고 쓴 문장. 가상 화자의 속말과 통념도 여기.
- `인용`: 실존 인물의 발언, 문헌의 문장. 지어내지 않는다.
- `표기`: 날짜, 장소, 이름과 직함, 출처, 수치 라벨. 작은 글씨.
- `제목`: 영상의 제목 카드. 한 편에 한 장.
- `이름`: 개념이나 인물의 이름만 크게 띄우는 카드, 소제목.
- `무문장`: 장면만.

`visual.type`: `실사`, `기록`, `재연`, `일러스트`, `도해`, `타이포`, `스톡`

## 5. 짧은 예

```json
{
  "meta": {
    "title": "엘리베이터 닫힘 버튼은 왜 있을까 | 누르는 사람을 위한 버튼",
    "screen_title": "닫히지 않는 버튼",
    "lang": "ko",
    "family": "A1",
    "family_reason": "누구나 눌러 본 버튼에 대한 통념을 뒤집는다",
    "target_seconds": 300,
    "hook_mode": "감춤",
    "logline": "(예시용 가상 대본)",
    "audience_belief": "닫힘 버튼을 누르면 문이 빨리 닫힌다",
    "axis_fact": "(예시)",
    "withhold": ["닫힘 버튼", "엘리베이터"],
    "ending": { "type": "질문", "callback": "세 번째", "callback_kind": "낱말" },
    "materials": "재연, 도해",
    "sources": []
  },
  "beats": [
    { "id": "b1", "name": "훅", "job": "버튼을 거듭 누르는 손으로 조급함을 보여 준다",
      "scene": "어디서 무엇을 누르는지 보이는 손", "text": "누르는 사람의 속말과 횟수" }
  ],
  "cards": [
    {
      "id": "c01", "beat": "b1", "t": 0, "d": 3, "kind": "무문장", "lines": [],
      "visual": { "type": "재연", "desc": "버튼 위에서 멈칫하는 손가락 클로즈업", "carries": "어디인지, 무엇을 하려는지", "callback": true }
    },
    {
      "id": "c02", "beat": "b1", "t": 3, "d": 6, "kind": "편집",
      "lines": ["또 눌렀다", "세 번째다"], "em": "세 번째", "voice": "독백",
      "visual": { "type": "재연", "desc": "(앞 장면 계속) 손가락이 같은 버튼을 다시 누른다", "carries": "누르는 대상. 문장은 횟수만 말한다" },
      "sound": "낮은 기계음, 음악 없음"
    }
  ]
}
```

위 예는 필드 모양을 보여 주기 위한 것이고 내용은 지어낸 것이다.

리드형(`C`, `D1`)은 `meta`가 조금 다르다. `withhold` 대신 `lead`를 적고, 날짜와 출처는 문장 카드의 `label`로 붙인다.

```json
{
  "meta": { "family": "C", "hook_mode": "리드", "lead": "이 다리는 개통 첫날 한 사람도 건너지 못했다",
            "ending": { "type": "사실", "callback": "첫 장면의 빈 다리", "callback_kind": "장면" } },
  "cards": [
    { "id": "c01", "beat": "b1", "t": 0, "d": 5, "kind": "편집",
      "lines": ["이 다리는", "개통 첫날"],
      "visual": { "type": "기록", "desc": "안개 낀 빈 다리의 옛 사진", "carries": "다리의 생김새와 시대", "callback": true } },
    { "id": "c02", "beat": "b1", "t": 5, "d": 6, "kind": "편집",
      "lines": ["한 사람도", "건너지 못했다"], "em": "한 사람도",
      "label": "1931년 5월 (가상의 예)",
      "visual": { "type": "기록", "desc": "(앞 장면 계속) 다리 입구의 닫힌 차단기로 다가간다", "carries": "건너지 못한 까닭의 단서" } }
  ]
}
```

## 6. 여러 편을 한 시트에

```
python scripts/build_sheet.py --scripts a.json b.json c.json --out 시트.html --title "가편집 시트"
```

여러 대본을 주면 한 HTML 안에서 탭으로 넘겨 본다. `--lint-only`를 붙이면 HTML을 만들지 않고 검수 결과만 출력하며, `실패`가 있으면 종료 코드 1을 낸다.
