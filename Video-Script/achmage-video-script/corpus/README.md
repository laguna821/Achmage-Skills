# 조사 원자료

이 스킬의 규칙과 사례집이 나온 조사의 원자료다. **방송 원문이 그대로 들어 있다.** 사례집(`references/casebook/`)은 같은 조사를 분석으로 정리한 것이고, 거기서는 인용을 줄였다. 문장이 실제로 어떻게 끊기고 이어지는지는 여기서만 보인다.

## 무엇이 있나

| 경로 | 내용 | 수 |
|---|---|---|
| `화면문장_로그/<채널>/<영상ID>.md` | 영상별 화면 문장 원문 로그(시각, 원문, 장면, 편집/인용/표기 구분)와 구조 메모 | 159 |
| `자막_트랜스크립트/` | 수집한 유튜브 자막 트랙과 ViewSpace 공식 전사 | 103 |
| `채널별_분석/*.md` | 채널별 상세 분석 원본(인용을 줄이지 않은 것). 지식채널e는 partA, partB, classic과 종합 | 30 |
| `채널별_대본_작법_분석_보고서.md` | 채널별 분석을 묶은 보고서 원본 | 1 |
| `지식채널e_유튜브_전편목록_1049편.csv` | 지식채널e 유튜브 채널 전편의 제목, 길이, 조회수, 주소(2026-11-10 수집) | 1 |
| `_index.json`, `_format_stats.json` | 표본 색인과 채널별 자막 트랙 집계 | 2 |
| `_분석지침.md` | 영상별 로그와 채널별 분석의 작성 기준 | 1 |

화면 판독에 쓴 프레임 묶음(`콘택트시트/`, 81편 558장)은 이 판에 들어 있지 않다. `_index.json`의 `sheetsDir`가 가리키는 폴더는 없다.

## 언제 여나

- **카드를 쓰기 전에(6단계).** 고른 갈래의 본보기 영상 1~2편의 로그를 연다. 사례집의 `episodes/<코드>/<영상ID>.md`와 같은 영상이 `화면문장_로그/<채널>/<영상ID>.md`에 있다. 표의 "화면 문장 (원문)" 칸에서 볼 것: 한 문장이 카드 몇 장에 어떻게 나뉘는지, 앞 카드가 어디서 끊기는지, 줄바꿈(`/`), 접속어가 홀로 서는 자리, 인용과 편집 문장이 번갈아 놓이는 차례.
- 사례집의 인용이 `…`로 줄어 있어 앞뒤가 궁금할 때.
- 스킬의 규칙을 고치거나 새 갈래를 더할 때. 규칙을 바꾸기 전에 원문 로그에서 반례를 찾는다.

전부 읽지 않는다. 한 번에 로그 1~2편이면 된다.

## 지킬 것

- **대본에 원문을 가져다 쓰지 않는다.** 구조와 호흡만 본다. 낱말, 비유, 문장을 옮기지 않는다.
- 로그의 문장과 자막의 저작권은 각 방송사와 제작사에 있다. 이 폴더는 연구와 비평을 위한 기록이며 스킬의 MIT 라이선스가 적용되지 않는다(`NOTICE.md`).
