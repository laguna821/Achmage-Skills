품질 QA 체크리스트

  • 레이어 순서배경 이미지 → 필터/스크림 → 카드 표면 → 텍스트/SVG 순서.

#viewport / .slide / .active

1920×1080 런타임

브라우저 크기와 상관없이 16:9 슬라이드가 항상 같은 좌표계로 보이게 하는 기본 무대.

언제 쓰나

모든 HTML PPT의 첫 번째 규칙. 화면이 깨지지 않게 하려면 슬라이드 내부는 항상 1920×1080 기준으로 배치한다.

레이어 구조

  • #viewport: 화면 가운데 정렬 무대
  • .slide: 1920×1080 고정 캔버스
  • .active: 현재 슬라이드만 표시
  • --deck-scale: 화면 크기에 맞춰 축소

AI 재현 프롬프트

모든 슬라이드는 1920×1080으로 만들고, 브라우저에는 scale로만 맞춰. 현재 장면은 `.active`만 보이게 해.

실패 방지

  • 슬라이드 내부를 vw/vh로 직접 짜면 캡처와 모바일에서 흔들린다.
  • 텍스트 위치는 1920×1080 좌표 기준으로 잡는다.
CSS 핵심
#viewport{position:fixed;inset:0;display:flex;align-items:center;justify-content:center;background:#000;}
.slide{position:absolute;top:50%;left:50%;width:1920px;height:1080px;transform:translate(-50%,-50%) scale(var(--deck-scale,1));display:none;overflow:hidden;}
.slide.active{display:block;}
HTML 예시
<div id="viewport">
  <section class="slide active" data-slide="1">...</section>
  <section class="slide" data-slide="2">...</section>
</div>

--img1~--img5 / .img1~.img5

Raw 5 이미지 바인딩

다섯 장의 원본 이미지를 CSS 변수에 넣고, 모든 배경·도형·카드에서 반복해 쓰는 장치.

언제 쓰나

이미지 5장만으로 20~40장 덱을 만들 때. 이미지 자체보다 CSS 편집 방식으로 장면 수를 늘린다.

레이어 구조

  • :root: 이미지 5장을 변수로 저장
  • .img1~.img5: 각 요소의 배경에 연결
  • 텍스트는 HTML 레이어로 따로 올림

AI 재현 프롬프트

Raw 5 이미지를 `--img1`부터 `--img5`까지 등록하고, 각 이미지 패널에는 `.img1` 같은 짧은 클래스로 연결해.

실패 방지

  • 이미지를 HTML img 태그로 반복하면 교체와 필터가 어렵다.
  • 같은 raw라도 배경 위치와 필터를 바꿔 새 장면처럼 만든다.
CSS 핵심
:root{--img1:url(raw1.webp);--img2:url(raw2.webp);--img3:url(raw3.webp);--img4:url(raw4.webp);--img5:url(raw5.webp);}
.img1{background-image:var(--img1)} .img2{background-image:var(--img2)} .img3{background-image:var(--img3)} .img4{background-image:var(--img4)} .img5{background-image:var(--img5)}
HTML 예시
<div class="panel image img1"></div>
<div class="shape arch img5"></div>
<article class="material-image-card" style="--card-img:var(--img3)">...</article>

#controller.auto-hide / .touch-zone

자동 숨김 네비게이션

슬라이드 이동 때만 우측 하단 컨트롤러를 잠깐 보이고, 평소에는 숨기는 방식.

언제 쓰나

완성 발표 모드. 화면에 번호 목록과 버튼이 계속 보이면 덱의 몰입감이 깨진다.

레이어 구조

  • #controller: 우측 하단 컨트롤러
  • .auto-hide: 숨김 상태
  • .touch-zone: 모바일 좌우 터치 영역
  • JS: 이동 시 show 후 타이머로 숨김

AI 재현 프롬프트

왼쪽 하단 슬라이드 번호 목록은 빼고, 우측 하단 컨트롤러는 이동할 때만 1초 정도 보이게 해.

실패 방지

  • 왼쪽 하단 전체 번호 목록은 만들지 않는다.
  • 컨트롤러가 항상 보이면 발표 화면이 어수선하다.
CSS 핵심
#controller{position:fixed;right:24px;bottom:24px;z-index:50;opacity:1;transition:opacity .18s ease,transform .18s ease;}
#controller.auto-hide{opacity:0;transform:translateY(14px);pointer-events:none;}
.touch-zone{display:none;}
@media(pointer:coarse),(max-width:900px){.touch-zone{display:block;position:fixed;top:0;bottom:0;width:34vw;z-index:45;opacity:0}.touch-left{left:0}.touch-right{right:0}}
HTML 예시
<div id="controller" class="auto-hide"><button>‹</button><span class="counter">1 / 20</span><button>›</button></div>
<div class="touch-zone touch-left"></div><div class="touch-zone touch-right"></div>

.masked-word

글자 이미지 마스크

큰 글자 내부에 이미지를 채워 넣어 키워드 자체를 비주얼로 만드는 기법.

언제 쓰나

표지, 챕터 오프너, 지역명·브랜드명·짧은 키워드 강조.

레이어 구조

  • 텍스트 요소 자체가 마스크
  • color:transparent
  • background-clip:text
  • 이미지는 background-image로 연결

AI 재현 프롬프트

짧은 단어를 `.masked-word`로 크게 쓰고, 배경 이미지를 글자 안으로만 보이게 해.

실패 방지

  • 글자가 길면 효과가 약해진다.
  • 얇은 폰트보다 초두꺼운 폰트가 좋다.
CSS 핵심
.masked-word{font-size:150px;line-height:.9;font-weight:950;letter-spacing:-.09em;color:transparent;-webkit-background-clip:text;background-clip:text;background-size:cover;background-position:center;}
HTML 예시
<div class="masked-word" style="background-image:var(--img3)">SEONGSU</div>

.shape-mask-scene / .mask-arch / .mask-circle

도형 마스크 크롭

사진을 원, 아치, 사선 도형으로 잘라서 단순 배치보다 고급스럽게 보이게 하는 기법.

언제 쓰나

인물, 제품, 공간 컷을 부드럽게 보여주는 소개 슬라이드.

레이어 구조

  • .shape-mask-scene: 도형 배치 무대
  • .mask-arch: 아치형 크롭
  • .mask-circle: 원형 크롭
  • clip-path 또는 border-radius 사용

AI 재현 프롬프트

네모 사진을 그대로 놓지 말고 `.mask-arch`, `.mask-circle` 같은 도형 마스크로 잘라서 써.

실패 방지

  • 도형이 너무 많으면 콜라주처럼 산만해진다.
  • 핵심 피사체가 잘리지 않도록 background-position을 조정한다.
CSS 핵심
.shape-mask-scene{position:relative;height:100%;}
.mask-arch{position:absolute;width:520px;height:620px;background-size:cover;background-position:center;clip-path:polygon(0 22%,0 100%,100% 100%,100% 22%,92% 0,8% 0);}
.mask-circle{position:absolute;width:430px;height:430px;border-radius:50%;background-size:cover;background-position:center;}
HTML 예시
<div class="shape-mask-scene"><div class="mask-arch img1"></div><div class="mask-circle img4"></div></div>

.behind-image-scene / .faint-shape / .scrim

텍스트 뒤 희미한 이미지

이미지를 글자 뒤에 아주 약하게 깔고, 스크림으로 가독성을 보정하는 정보형 기법.

언제 쓰나

텍스트가 중심이고 이미지는 분위기만 줘야 하는 보고서·전략 슬라이드.

레이어 구조

  • .faint-shape: 희미한 이미지 도형
  • .scrim: 글자 영역을 안정시키는 반투명 막
  • .text-wrap: 실제 메시지

AI 재현 프롬프트

이미지는 뒤에 10~20% 정도로만 남기고, 글자 앞에는 스크림을 깔아 정보가 먼저 읽히게 해.

실패 방지

  • 이미지가 30% 이상 강하면 글자가 흔들린다.
  • 스크림 없이 회색 글자를 올리면 대부분 안 읽힌다.
CSS 핵심
.behind-image-scene{position:relative;}
.faint-shape{position:absolute;right:110px;top:120px;width:700px;height:500px;opacity:.17;background-size:cover;background-position:center;clip-path:polygon(18% 0,82% 0,100% 50%,82% 100%,18% 100%,0 50%);}
.scrim{position:absolute;inset:0;background:linear-gradient(90deg,rgba(248,251,255,.95),rgba(248,251,255,.72));}
HTML 예시
<div class="behind-image-scene"><div class="faint-shape img2"></div><div class="scrim"></div><div class="text-wrap">핵심 메시지</div></div>

.wash-scene / .wash-layer

워시 배경

사진을 흐리고 낮은 불투명도로 깔아 정보 배경처럼 만드는 기법.

언제 쓰나

설명 많은 장표, 요약, 맥락 설명, 이미지가 너무 강할 때.

레이어 구조

  • .wash-scene: 이미지 배경
  • .wash-scene:before: 흐린 이미지 복제
  • .wash-layer: 흰색/어두운 막
  • .wash-content: 텍스트

AI 재현 프롬프트

배경 이미지를 워시처럼 약하게 깔고, 앞쪽 텍스트가 먼저 보이도록 `.wash-layer`를 얹어.

실패 방지

  • blur가 너무 낮으면 사진이 경쟁한다.
  • 스크림이 너무 약하면 본문이 안 읽힌다.
CSS 핵심
.wash-scene{position:relative;overflow:hidden;background-size:cover;background-position:center;border-radius:30px;}
.wash-scene:before{content:'';position:absolute;inset:-24px;background:inherit;background-size:cover;background-position:center;filter:blur(12px) saturate(.85);opacity:.22;transform:scale(1.04);}
.wash-layer{position:absolute;inset:0;background:rgba(250,246,236,.70);}
.wash-content{position:relative;z-index:2;padding:54px;}
HTML 예시
<div class="wash-scene img3"><div class="wash-layer strong"></div><div class="wash-content"><h2>핵심 메시지</h2></div></div>
