Raw 5 이미지 변수와 바인딩

--img1~--img5 / .img1~.img5

1) 기법 이름

다섯 장의 원본 이미지를 CSS 변수로 등록하고, 각 패널이나 도형에 클래스 한 줄로 연결하는 기본 장치입니다. 슬라이드마다 새 이미지를 만들지 않고, 같은 이미지를 계속 다르게 잘라 쓰는 출발점입니다.

원리 해설

사진 자체를 HTML에 직접 반복해서 넣지 않고, CSS 변수에 저장합니다. 이후 .img1, .img2 같은 짧은 클래스를 붙이면 해당 요소의 배경 이미지가 바로 연결됩니다. 즉, Raw 5를 전체 덱의 공용 재료 창고로 만드는 방식입니다.

AI에게 이렇게 말하기
Raw 5 이미지를 CSS 변수로 등록하고, 각 이미지 패널은 img1~img5 클래스 또는 inline background-image로 바인딩해.
2) 코드 원문
:root{
  --img1:url('raw1.webp');
  --img2:url('raw2.webp');
  --img3:url('raw3.webp');
  --img4:url('raw4.webp');
  --img5:url('raw5.webp');
}
.img1{background-image:var(--img1)}
.img2{background-image:var(--img2)}
.img3{background-image:var(--img3)}
.img4{background-image:var(--img4)}
.img5{background-image:var(--img5)}
HTML 사용 예시
<div class="panel image img1"></div>
<div class="shape arch img5"></div>
<div class="masked-word" style="background-image:var(--img3)">대학</div>

.masked-word

1) 기법 이름

원리 해설

글자를 아주 굵고 크게 만든 뒤, 색을 투명하게 지웁니다. 그 다음 background-clip:text로 배경 사진을 글자 모양 안에만 보이게 합니다. 포토샵의 클리핑 마스크를 글자에 건 것과 같습니다.

2) 코드 원문
.masked-word{
  font-size:140px;
  line-height:.92;
  font-weight:900;
  letter-spacing:-.08em;
  color:transparent;

  background-clip:text;

텍스트 뒤 희미한 이미지 레이어

.behind-image-scene / .faint-shape / .scrim

1) 기법 이름

사진을 글자 뒤쪽에 아주 약하게 깔고, 반투명 흰 막을 덮어 가독성을 유지하는 기법입니다.

원리 해설

배경 이미지의 opacity를 낮추면 분위기는 남고 정보 방해는 줄어듭니다. 여기에 scrim이라는 반투명 막을 올리면 텍스트 영역이 안정됩니다. 글씨가 먼저, 이미지는 뒤에서 분위기만 잡는 구조입니다.

AI에게 이렇게 말하기
본문 뒤쪽 오른쪽에 .faint-shape 이미지를 낮은 불투명도로 깔고, .scrim으로 글씨 영역 가독성을 보정해.
2) 코드 원문
.behind-image-scene{position:relative;}
.faint-shape{
  position:absolute;
  right:110px;
  top:120px;
  width:700px;
  height:500px;
  opacity:.17;
  background-size:cover;
  background-position:center;
  clip-path:polygon(18% 0,82% 0,100% 50%,82% 100%,18% 100%,0 50%);
}
.scrim{
  position:absolute;
  inset:0;
  background:linear-gradient(90deg,rgba(248,251,255,.95),rgba(248,251,255,.72));
}
HTML 사용 예시
<div class="behind-image-scene">
  <div class="faint-shape img2"></div>
  <div class="scrim"></div>
  <div class="text-wrap">핵심 메시지</div>
</div>

AI에게 이렇게 말하기
오른쪽 영역에 .frame.circle, .frame.slant, .frame.rounded를 흩뿌리듯 배치해서 이미지가 하단에 몰리지 않게 균형을 잡아.

.wash-scene / .wash-layer

1) 기법 이름

이미지를 슬라이드 전체 배경으로 크게 깔되, 흐림과 투명도를 적용해 은은한 질감처럼 만드는 기법입니다.

원리 해설

이미지를 배경에 크게 깔면 너무 강할 수 있습니다. 그래서 :before로 이미지를 크게 깔고 blur와 opacity를 낮춘 뒤, wash-layer로 흰색 또는 어두운 반투명 막을 덮습니다.

AI에게 이렇게 말하기
배경은 .wash-scene 방식으로 raw4를 아주 옅게 깔고, 그 위에 정보 카드를 배치해.
2) 코드 원문
.wash-scene{
  position:relative;
  overflow:hidden;
  background-size:cover;
  background-position:center;
}
.wash-scene:before{
  content:'';
  position:absolute;
  inset:0;
  background-image:inherit;
  background-size:cover;
  background-position:center;
  filter:blur(6px) saturate(.9);
  opacity:.18;
  transform:scale(1.06);
}
.wash-layer{
  position:absolute;
  inset:0;
  background:rgba(248,251,255,.54);
}
HTML 사용 예시
<div class="wash-scene" style="background-image:var(--img4)">
  <div class="wash-layer"></div>
  <div class="wash-content">텍스트 카드</div>
</div>

V7 CSS TECHNIQUE

1920×1080 고정 캔버스와 모바일 확인 런타임

.slide / #viewport / touch-zone / auto-hide-nav

1) 기법 이름

HTML PPT를 데스크탑 비율로 유지하면서 브라우저 크기에 맞게 축소하고, 모바일에서는 스와이프와 엣지 탭으로 넘기는 런타임 구조입니다.

원리 해설

AI에게 이렇게 말하기
최종 HTML은 1920×1080 고정 슬라이드로 만들고, viewport scale, 키보드 이동, 모바일 스와이프, 좌우 엣지 탭, 자동 숨김 네비게이션을 포함해.
