This is a presentation-specific composition of full member resources, not the union of competing builder commands. User requirements > confirmed brand and preservation contract > this scoped workflow > applicable member guidance. Explain a real conflict in the production report; do not silently replace installed user choices.

Read the full member instructions then these explicit scoped exceptions. They are integration decisions, not edits to upstream originals. The member folders are passive resources named INSTRUCTIONS.md to avoid six competing SKILL.md auto-triggers. Resolve all member scripts relative to this package; ignore historical CLAUDE_PLUGIN_ROOT / vault paths in upstream guidance.

The user's presentation request authorizes ordinary brief, storyline, design and generation work. Do not impose a separate component-consulting nod/approval gate on each stage. Ask only for genuinely missing essential facts or authorization. When no manuscript is supplied, author a draft from the brief and label illustrative examples; never invent supplied source material, real survey results or affiliation.

For corpus candidate retrieval, invoke members/component-consulting-v3/scripts/corpus_query.py with --help, then query intent and --deck-safe. Preserve code source and license attribution for any actually reused code. Do not claim a corpus component was used when a native approved pattern already answers the message. Full corpus inclusion is not permission to add React/network runtime to an offline deck.
Query members/ui-ux-pro-max/scripts/search.py with the brief and --domain ux for relevant accessibility/touch/responsive questions. Do not request a new design system when the brand is already fixed.
Run consulting content review against the storyline and evidence, not against unrelated warm-palette HTML templates.
Respect requested slide count and duration. The consulting member's cover/overview/conclusion/back-cover roles may be merged or omitted when they add no message; they do not force four structural pages into a three-slide request.
The default no-image document profile explicitly exempts image quotas and scene texture checks. If real imagery is requested, retain provenance, actual asset inspection and the member's RAW OK handoff; do not fabricate approval.
Use the host's permitted browser tools. Codex CUA-only environments must use CUA; a bundled script never grants permission to bypass host tool restrictions.
