# 디자인과 반응형

## 기준

현재 요청이 다르게 정하지 않는 한 Field Guide v7을 표준으로 사용한다. 원본 SameTone과 로고를 쓰고 흰 바탕·네이비 구조·블루 동작·틸 강조를 유지한다. 일반 스킬의 A2Z/Pretendard 대체, 장식 쿼터, 화면마다 큰 다크 히어로를 적용하지 않는다.

DESIGN.md는 값과 사용 이유의 정본이다. Google alpha 명세의 YAML 토큰과 여덟 본문 절 순서를 따른다. 문서와 CSS를 따로 고쳐 값이 갈라지게 두지 않는다. styles.css는 구조, tokens.css는 DESIGN.md에서 생성된 색·글자·간격 값을 담당한다.

## 크기와 읽기

1440px 최대 캔버스와 같은 좌측 기준선을 유지한다. 장문은 72ch 안에서 읽힌다. 본문 17px, 행간 1.95가 기본이며 제목은 현재 계층을 유지한다. 링크·버튼·목차는 글자가 작아도 터치 영역은 44px 이상으로 만든다.

네이비 구역에는 흰색 본문과 대비가 확보된 보조 글자를 쓴다. 밝은 틸은 흰 바탕의 작은 글자가 아니라 선·표식에 사용한다. 라인과 구획으로 깊이를 만들고 커다란 그림자와 반복 둥근 카드로 채우지 않는다.

## 화면이 좁아질 때

- 1200px 이하: 히어로 간격과 사이드바 폭을 줄인다.
- 1060px 이하: 상단 메뉴를 펼침 메뉴로 전환하고 모음집을 한 열로 만든다.
- 1000px 이하: 상세 사이드바를 모바일 목차로 바꾼다.
- 760px 이하: 히어로·구조·목차를 세로로 쌓고 모음집 분류를 선택 상자로 바꾼다.
- 400px 이하: 바깥 여백과 로고 폭을 줄인다. 본문은 작게 축소하지 않는다.

고정 헤더와 목차의 실제 높이를 고려해 앵커가 가려지지 않게 한다. 긴 URL·명령은 줄바꿈하고 코드·넓은 표는 해당 영역 안에서만 스크롤한다. 페이지 전체의 가로 스크롤로 해결하지 않는다.

## 동작

일반 문서는 실제 href가 있는 링크로 이동한다. 검색창은 키보드와 Escape를 지원하고 닫힌 뒤 초점을 돌려준다. 펼침 메뉴는 aria-expanded, 활성 필터는 aria-pressed를 표시한다. 언어 전환 시 현재 경로와 절을 유지한다.

기본 테마는 밝은 화면이다. 사용자가 선택한 테마는 로컬에 보존한다. 모션은 상태 변화를 이해시키는 짧은 전환에 한정하고 prefers-reduced-motion을 존중한다.
