# 검수와 전달

## 자동 검사

1. npm run check: 타입, 콘텐츠 참조, 한국어·영어, 링크와 자산 경로, 원문·Markdown 일치를 확인한다.
2. npm run design:lint: 공식 @google/design.md 0.4.0으로 검사한다. 오류 0, 대비·끊긴 참조·순서 경고를 해결한다. 정보 메시지는 오류로 세지 않는다.
3. npm run build: 언어별 HTML·검색·원문·전체 Markdown을 만든다. 생성된 HTML의 핵심 내용은 JavaScript 없이도 읽을 수 있어야 한다.

## 실제 화면

375·390·768·1024·1440px에서 랜딩, 긴 상세, 모음집, 원문을 본다. 모든 작은 상태를 스크린샷으로 쌓는 대신 대표 화면과 발견한 문제를 기록한다.

- 제목·문단을 읽을 수 있고 가로 넘침·겹침이 없는가.
- 소목차가 현재 장에서 펼쳐지고 링크 이동 후 제목이 헤더 아래 보이는가.
- 메뉴 열기/닫기, 한국어↔영어 같은 경로, 뒤로 가기가 되는가.
- 검색, 분류, 0개 결과, 초기화, 복사가 되는가.
- 키보드 초점, Escape, 다크 화면, 줄어든 모션을 확인했는가.
- 원문 화면·다운로드·전체 Markdown의 내용이 일치하는가.
- 장식·작은 레이블·조작 횟수가 내용을 읽는 데 방해하지 않는가.

## 설명 검토

독자가 원문을 모른다고 가정하고 주체·입력·행동·결과가 빠진 절을 찾는다. 문장 길이나 문서 수를 이해도의 대리 지표로 삼지 않는다. 상당한 콘텐츠 재작성에는 독립적인 읽기 검토를 사용하되 실제 사용자 이해도 시험으로 표현하지 않는다.

## 전달과 범위

요청된 배포가 있으면 현재 프로젝트의 검증·배포 절차를 사용하고 공개 화면·본문을 다시 확인한다. 배포 요청이 없으면 로컬 미리보기와 빌드를 제공한다. 스크린샷 검사, 실제 클릭, 원격 HTTP 확인, 실제 기기 사용은 각각 수행한 만큼만 보고한다.

등록된 임시 도구는 실제 작업이 끝나면 반환한다. 중요한 수정 근거와 재현 방법은 남기고 의존성·임시 빌드를 공용 스킬에 넣지 않는다.
