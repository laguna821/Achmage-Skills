# 정보 배치표

현재 content/portfolio.json은 학습용 전시 아카이브 예시다. 실제 프로젝트 자료로 교체한 뒤 각 행의 근거와 공개 범위를 확인한다.

| 페이지·구획 | 독자의 질문 | 설명 | 예시·근거 | 화면 | 다음 읽기 |
|---|---|---|---|---|---|
| 소개 | 무엇을 만들었나 | 전시 자료를 한곳에서 찾는 아카이브 | 학습용 상황임을 표시 | 설명 + 구체적 흐름 | 시작한 이유 |
| 모음집 | 어떤 자료가 있나 | 작품·인터뷰·연표 | 가상 예시 항목 | 분류와 검색 | 자료 정리 방법 |
| 상세 | 어떻게 만들었나 | 파일 선택, 기록, 확인 | 정상·누락 사례 | 펼쳐진 소목차 + 본문 | 원문 |
| 자료실 | 실제 기록을 볼 수 있나 | 학습용 기획안 전문 | 공개 샘플 원문 | 전체 읽기·다운로드 | 전체 설명 |
| 전체 설명 | 다른 도구에 전달할 수 있나 | 본문과 원문을 모두 제공 | 같은 콘텐츠 데이터 | HTML + Markdown | 각 상세 장 |
