# 1.0.0 검증 범위

검증일: 2026-10-25. Windows의 Codex 환경에서 제작·검증했습니다.

## 확인한 내용

- 기본 가상 예제, 기존 Field Guide 재현본, 별도 수업 자료집의 3개 프로젝트를 빌드했습니다.
- 재현본에는 16개 장, 기능 항목 387개, 공개 원문 3개를 넣었습니다. 수업 자료집은 별도 검수 에이전트가 새로운 주제로 작성한 6개 장·14개 절입니다.
- 총 91개 생성 HTML 문서의 내부 링크·앵커와 전체 HTML/Markdown의 내용 보존을 검사했습니다. 원문은 입력 바이트와 일치했습니다.
- TypeScript, 콘텐츠·브랜드 검사, 공식 @google/design.md 0.4.0 검사, skill-creator 검사를 통과했습니다.
- 실제 브라우저에서 주요 화면의 메뉴·세부 목차·검색·필터·언어 전환·원문·복사와 키보드 동작을 확인했습니다.
- 375·390·768·1024·1440px 화면 너비에서 가로 넘침과 반응형 구성을 확인했습니다.
- Achmage OS 원본·Wiki·라우팅 등록과 현재 Codex 설치본을 확인했습니다.
- 공개 스킬 28개 파일을 검증된 설치본·배포 매니페스트와 비교합니다. ZIP에는 같은 파일을 넣었으며 개인 경로·자격증명·작업 기록을 포함하지 않습니다.
- 공개 플러그인의 경로·버전·마켓플레이스 항목과 ZIP 해시를 확인합니다.

## 확인하지 않은 내용

91개 HTML 문서 모두를 육안 검사한 것은 아닙니다. 화면 크기를 바꿔 시험했으며 실제 휴대전화와 다른 PC에서의 실행은 아직 확인하지 않았습니다. macOS·Linux와 다른 AI 앱의 자동 선택·네이티브 실행도 별도 검증이 필요합니다.

이번 공개 등록은 이미 검증한 파일의 배포입니다. 새 콘텐츠로 만든 모든 사이트의 품질을 보증하지 않습니다. 실제 사용할 자료를 넣은 다음 스킬의 검수 절차를 다시 수행해야 합니다.

Google DESIGN.md는 alpha 명세이며 검사기 버전을 0.4.0으로 고정했습니다. 명세나 의존성을 갱신할 때에는 해당 버전으로 다시 검증합니다.

Pele 도식, CMDS 이미지 제작, R2 업로드, Eagle 정리는 기본 템플릿 실행의 필수 단계가 아닙니다. 이 공개 스킬의 설치만으로 해당 도구나 계정이 함께 설치·연결되지는 않습니다.
