# 판정표 규격 (`받침.json`)

판정표는 초고의 카드마다 "이것을 어디서, 어떻게 확인했나"를 적는 파일이다. UTF-8로 저장한다. `scripts/check_backing.py`가 이 파일과 `대본.json`을 함께 읽어 검수하고 요약과 시트를 만든다. 없는 것은 빈 배열로 둔다. 칸을 지우지 않는다.

## 1. 전체 모양

```json
{
  "meta": { "script": "대본.json", "title": "초고의 제목", "story": "초고가 하는 이야기 한두 문장", "checked_on": "2026-11-16" },
  "sources": [ ... ],
  "cards": [ ... ],
  "hinges": [ ... ],
  "quotes": [ ... ],
  "disagreements": [ ... ],
  "extras": [ ... ],
  "visuals": [ ... ],
  "unverified": [ ... ]
}
```

## 2. `sources`

```json
{ "id": "B1", "label": "저자, 제목, 발행처, 연도", "url": "https://...",
  "tier": "1차 기록", "access": "열림", "accessed": "2026-11-16",
  "status": "직접 확인", "checked": "이 출처에서 확인한 내용 한 줄", "interest": "" }
```

- 번호는 `B1`부터. 초고의 출처 번호(`S1`)와 섞이지 않게 한다. 초고가 쓴 자료를 다시 열었으면 여기에 다시 올린다.
- `tier`: `1차 기록`, `논문`, `공식 통계`, `전문가`, `2차`, `3차`, `자기 발표`. 뜻은 `02` 2절. `익명 웹`은 출처가 될 수 없다.
- `status`: `직접 확인`, `직접 확인 (일부는 발췌로 확인)`, `주소가 열리지 않음, 발췌로 확인`, `주소가 열리지 않음, 보관 사본으로 확인`. 뜻은 `02` 4절. 일부만 읽었으면 `checked`에 읽은 범위를 적는다. 근거 대목은 직접 읽은 곳에서만 옮긴다.

## 3. `cards`

진술하는 카드마다 한 줄이다(`01` 2절).

```json
{ "id": "c17", "text": "화면 문장. 줄바꿈은 ' / '",
  "verdict": "세다", "strength": "단일 출처",
  "src": ["B4"], "where": "3쪽 둘째 문단", "evidence": "출처의 해당 대목, 원어 그대로 짧게",
  "conditions": "", "calc": "",
  "problem": "무엇이 어떻게 다른지 한두 문장",
  "fix": "구석 표기",
  "label": "○○의 메모, 1901",
  "must_keep": "",
  "alternatives": [ { "fact": "그 자리에 쓸 수 있는 확인된 사실", "src": ["B7"], "where": "...", "evidence": "..." } ] }
```

| 칸 | 내용 |
|---|---|
| `id` | 대본의 카드 번호 그대로 |
| `text` | 그 카드의 화면 문장 |
| `verdict` | `받쳐진다`, `세다`, `없다`, `틀리다` (`01` 3절) |
| `strength` | 그 문장이 기대는 사실의 세기: `확정`, `단일 출처`, `다툼`, `미확인` |
| `src`, `where`, `evidence` | 근거. `받쳐진다`이면 셋 다 필수. 걸린 카드에도 찾은 데까지 적는다. `evidence`는 영어 60단어, 한국어 240자 이내 |
| `conditions`, `calc` | 수치의 조건, 계산식 (`04` 2절) |
| `problem` | 걸린 카드이면 필수. 무엇이 어떻게 다른지 |
| `fix` | 걸린 카드이면 필수. 가장 가볍게 고칠 길 하나: `구석 표기`, `낱말`, `조건`, `갈아 끼우기`, `빼기` (`05`) |
| `label` | `fix`가 `구석 표기`이면 필수. 화면 구석에 달 출처의 이름: 때, 곳, 사람이나 자료의 이름. 공백을 빼고 20자 이내. 검수 메모를 적지 않는다 |
| `must_keep` | `fix`가 `낱말`이나 `조건`이면 필수. 고칠 낱말, 또는 문장이 참이 되려면 꼭 들어가야 하는 조건이나 범위 |
| `alternatives` | `fix`가 `갈아 끼우기`이면 필수. 그 자리를 받칠 수 있는 확인된 사실과 근거. 대안 문장이 아니라 사실이다 |

`strength`를 정하는 법:

- `확정`: 1차 기록, 논문, 공식 통계가 직접 받치고 직접 열어 확인했다. 또는 서로 다른 원 기록에 기대는 독립된 출처 둘 이상이 같은 말을 한다.
- `단일 출처`: 출처가 하나이고 그것이 2차 서술, 회상, 한 사람의 메모다. 같은 기록을 옮긴 글 여럿은 출처 하나다.
- `다툼`: 출처끼리 어긋난다. `disagreements`에 한 줄이 있어야 한다.
- `미확인`: 발췌로만 보았거나 원문을 열지 못했다. `unverified`에 한 줄이 있어야 한다.
- 소장 기관이 자기 소장품에 대해 적은 것(언제 어디서 어떻게 나왔나, 어떤 상태인가)과 발굴 보고, 당사자가 그때 남긴 기록은 그 사실에 한해 `1차 기록`으로 다룬다. 같은 글의 연대 추정과 쓰임새 풀이는 해석이다.

## 4. `hinges`

```json
{ "what": "둘째 꺾임", "cards": ["c31", "c32", "c33"],
  "searched": "무엇으로 찾았나: 검색어와 연 자료",
  "found": "무엇이 나왔나. 안 나왔으면 안 나왔다고",
  "verdict": "조건을 달면 버틴다", "condition": "어떤 조건인가",
  "gap": "꺾임이 무엇을 뒤집는지 보이는 카드가 있는가. 없으면 그 자리를 채울 확인된 사실" }
```

- `what`: `첫 꺾임`, `둘째 꺾임`, `핵심 사실`, `마지막 한 줄`, `통념`.
- 대본의 꺾임 카드(`turn`)마다, 그리고 마지막 문장 카드에 하나씩 있어야 한다.
- `verdict`: `버틴다`, `조건을 달면 버틴다`, `못 버틴다`.

## 5. `quotes`

```json
{ "card": "c13", "screen": "화면의 인용문", "original": "원문 그대로",
  "speaker": "말한 사람과 자격", "said": "말한 때", "where": "출전과 쪽. 적힌 때",
  "earliest": "", "form": "번역·줄임", "verified": "원문 대조", "note": "" }
```

- 대본의 인용 카드마다 한 줄.
- `verified`: `원문 대조`(그 말이 실린 원 자료를 열어 글자 단위로 맞추었다) 또는 `재인용(원문 미확인)`. 누구를 거쳐 왔는지 `where`에 적는다.
- 말한 때와 적힌 때가 다르면 둘 다 적는다. 초고의 말한 이 줄이 틀렸으면 그 카드의 `verdict`는 `틀리다`다.
- 화면의 인용문에 원문에 없는 말이 들어 있으면 `note`에 적고 그 카드를 걸린 카드로 판정한다.

## 6. `disagreements`, `extras`, `unverified`

```json
"disagreements": [ { "about": "무엇이 갈리나",
  "positions": [ { "says": "...", "src": ["B3"] }, { "says": "...", "src": ["B6"] } ],
  "cards": ["c25"], "handling": "갈리지 않는 데까지만 말한다 / 한쪽이 원 기록에 가깝다 / 쓰지 않는다" } ],
"extras": [ { "what": "원자료에서 찾은 재료", "src": ["B5"], "where": "...", "evidence": "...", "fits": "어느 카드 근처에 맞나" } ],
"unverified": [ { "what": "...", "why": "...", "needed": "무엇을 열면 확인되나", "cards": ["c22"] } ]
```

- `extras`는 사람의 동작, 물건의 상태, 날짜, 문서의 낱말처럼 장면이 되는 것을 적는다. 평가와 요약은 적지 않는다. 쓸지는 선배가 정한다.
- `unverified`는 사람이 직접 열어야 하는 것이다. 무거운 카드에 걸리는 것부터 적는다.

## 7. `visuals`

```json
{ "id": "V1", "card": "c05", "what": "원고 15쪽의 해당 대목", "kind": "문서",
  "holder": "소장처", "url": "https://...", "file": "화면자료/c05_원고15쪽.png",
  "credit": "크레딧 표기", "license": "확인한 그대로", "use": "근거", "verified": "무엇을 대조했나" }
```

- `kind`: `실물`, `기록 사진`, `문서`, `도면`, `지도`, `데이터`, `현재 영상`.
- `use`: `근거`(편집자가 확인하려고 보는 갈무리) 또는 `화면 후보`(영상에 쓸 수 있는 자료).
- `license`: 확인한 그대로. 열려 있는 조건은 `퍼블릭 도메인`, `공유 저작물`, `CC0`, `CC BY ...`, `공공누리 ...`, `이용 허락 ...`으로 시작하게 적는다. 그 밖은 `확인 필요`나 `이용 불가`. 자세한 것은 `06`.
