# S0. 이야기로 다시 읽기

> 한 줄 판정: 아홉 묶음의 분석은 같은 노트에서 "물음, 자료, 확인, 구조, 근거, 덜어내기"를 물었다. 그래서 서사 논픽션의 필자들을 읽고도 검증하는 법만 뽑았다. 이 문서는 같은 노트를 "이야기를 어디서 찾았나, 무엇을 물어 왔나, 사실을 어떻게 이었나"로 다시 읽은 것이다. 이야깃거리를 찾는 일은 achmage-video-script 1.3.0으로 옮겼고, 그 스킬의 `references/08-이야깃거리-찾기.md`가 이 다시 읽기에 기댄다. 이 스킬(받침)은 주로 `clusters/G1.md`(출처와 검증)와 `clusters/V1.md`(영상 제작사의 검증 과정)에 기댄다.

## 0. 읽은 범위

- 다시 읽은 것: P1, P2, X2, K1 네 묶음의 노트 50건. 노트마다 "2. 발단", "4. 축이 되는 사실이나 장면", "5. 구조" 세 대목을 읽었고, P2는 묶음 분석 전문을 함께 읽었다.
- 읽지 않은 것: X1, X3, V1, K2, G1의 노트. 원 기사를 다시 열지도 않았다. 아래의 모든 서술은 노트에 적힌 것에 기댄다. 노트가 "확인 못함"이라고 적은 곳은 여기서도 모른다.
- 노트는 필자의 회고와 주석자의 평을 옮긴 것이다. 필자가 자기 작업을 좋게 말하는 자료라는 한계는 그대로다.

## 1. 이야기는 어디서 시작됐나

| 발단 | 노트 |
|---|---|
| 전문가들이 지나가는 말로 언급하는 것 가운데 하나. 한 논문에 두 이름이 번갈아 나왔다 | P2 hochschild-spain-texaco |
| 남의 책에서 한 문장도 안 되는 언급. 눈에 띄어 모든 자료를 읽었고, 주인공을 만난 때 쓸 수 있다고 확신했다 | P1 reveley-ckdu-el-salvador |
| 박물관의 단체 사진에서 한 부분이 오려져 있었다 | P2 grann-killers-flower-moon |
| 표류자들을 모은 웹사이트에서, 혼자 나선 남자들 사이의 유일한 부부 사진에 눈이 멈췄다. 그때는 큰 뉴스였는데 필자의 세대는 아무도 몰랐다 | P2 elmhirst-marriage-at-sea |
| 빙하에서 50년 된 카메라가 나왔다. 필자는 "이야기를 하는 이유"로 입구를 잡고 싶었다고 말한다 | P2 branch-ghosts-glacier |
| 사고 영상은 많은 사람이 보았는데 운전자는 인터뷰한 적이 없었다. "알아갈수록 흥미로운 아이디어는 좋은 신호" | P2 smiley-uber-vasquez |
| 과거 자료를 찾다가 후손이 훈장을 펼쳐 보이는 영상을 보았다 | K1 kbja-mbc-foreign-patriots |
| 대학 홍보실을 돌다가 한 법인류학자가 별 뜻 없이 한 말. 아이디어는 집에 앉아서는 얻지 못한다 | P1 wild-veld-bodies |
| 통계의 각주. 이것이 조금이라도 맞다면 이상한 일이 벌어지고 있다 | P2 yoffe-college-rape |
| 헤드라인 뉴스는 거기서 거기여서 작은 매체, 게시판, 출퇴근길 라디오에서 얻는다 | K1 jisik-e-sisain-newstapa |
| 검색되는 기사만으로는 부족하고 더할 것이 있어야 한다. 회의에서 마음을 움직이지 않으면 채택하지 않는다 | K1 jisik-e-kimhanjung-mediatoday |

읽히는 것: 발단은 주제의 이름이 아니었다. **물건 하나, 사진 한 장, 지나가는 한 줄, 묻지 않은 사람 하나**였다. 그리고 필자들은 그것이 이야기가 되는지를 따로 물었다: 왜 흥미로운지를 글자로 쓸 수 있나, 나에게만 새로운 것은 아닌가, 물을수록 문이 열리나(P1 craft-is-this-a-story).

## 2. 무엇으로 열었나

| 입구 | 노트 |
|---|---|
| 중환자실이 가득 찬 날, 호텔에서 행사장으로 가는 셔틀버스 | P1 guo-superspreader |
| 1950년대의 폭포, 물고기를 상자에 담는 열세 살 소년. 이어 1957년 댐 완공으로 폭포가 물에 잠겼다는 문장이 장면을 끊는다 | P1 oaster-pacific-lamprey |
| 생존자가 보여 준 나무 한 그루와, 지금은 메워진 그 자리 | P1 sokol-minamata-mercury |
| 이름이 있는 고래 한 마리의 흉터, 가족, 나이, 죽음 | P1 yong-right-whales |
| 카테터를 거부하던 남자가 네 살 아들의 말에 마음을 돌리는 순간 | P1 reveley-ckdu-el-salvador |
| 빙하에서 나온 카메라와 거기 붙은 이름표 | P2 branch-ghosts-glacier |
| 1973년 3월 4일 해 뜰 무렵의 빈 바다. 일상의 규칙을 먼저 세우고 곧 깨뜨린다 | P2 elmhirst-marriage-at-sea |
| 성당의 조각상에서 마을로. "영화의 첫 장면"처럼 | P2 junger-perfect-storm |
| 1925년 한 매장에서 청년이 측정기에 발을 넣는 장면 | X2 99pi-brannock |
| 1933년 10월 1일 일요일의 점심 | X2 atlas-eintopf |
| 1956년 4월 26일, 낡은 유조선 갑판에 올린 상자 58개 | X2 smithsonian-shipping-container |

읽히는 것: 입구는 **날짜와 곳이 있는 순간, 이름이 있는 사람, 손에 잡히는 물건**이었다. 배경 설명으로 연 글은 표본에 거의 없다. 한 필자는 역사부터 시작하면 눈이 풀린다고 말한다(P2 junger). 반례도 있다. 탐사 기사는 일화 없이 발견 한 문장으로 열기도 한다(P1 piller-failure-to-report). 필자는 규칙은 아니라고 덧붙인다.

## 3. 무엇으로 꺾었나

| 꺾는 사실 | 노트 |
|---|---|
| 오랜 전통처럼 쓰이는 낱말이 1930년 이전에는 들어 본 적 없는 말이었다 | X2 atlas-eintopf |
| 통념대로라면 떨어져 있어야 할, 영어에서 넷째로 흔한 글자쌍이 자판에 나란히 있다 | X2 smithsonian-qwerty |
| 그해 팔린 2만 4천 개의 대부분이 한 재단사가 만든 돈주머니에 들어갔다. 성공을 정한 것은 쓰임이었다 | X2 jstor-zipper |
| 문제는 상자가 아니라 규격이었고, 특허를 무상으로 열어 표준이 됐다 | X2 smithsonian-shipping-container |
| 동의서가 그 연구를 다른 이름의 프로그램으로 불렀다. 평가하지 않고 문서의 낱말 하나로 보여 준다 | P1 marchione-crispr-babies |
| 내부 직원이 미리 경고한 날짜가 찍힌 이메일. 주석자는 "취재의 선물"이라 부른다 | P1 guo-superspreader |
| 영안실이 해마다 3천 구를 큰 장부에 손으로 적는다. 주석자는 "한 방"이라 평한다 | P1 wild-veld-bodies |
| 결재 문서에 찍힌 도장 | K1 kbja-jtbc-referee |

읽히는 것: 꺾임은 평가나 해석이 아니라 **물증 하나**였다. 문서의 낱말, 날짜, 숫자, 도장. 그리고 통념의 낱말 하나를 정확히 건드린다. 지식채널e의 제작진은 구조를 "궁금증을 부르는 초반부, 반드시 등장하는 반전"이라고 말한다(K1 jisik-e-kimjinhyuk-peoplepower).

## 4. 어떻게 이었나

- **누군가 무언가를 원한다.** 이야기의 중심을 찾는 물음이다(P1 craft-naming-the-dog).
- **복잡한 재료일수록 구조는 더 단순해야 한다.** 조사가 끝나면 이야기 대여섯 개를 쓸 정보가 있다. 이 글이 무엇에 관한 것인지를 정해야 한다(P1 craft-naming-the-dog).
- **시간순이 바탕이고, 거기에 대비 하나를 끼운다.** 공개 발언과 내부 사실(P1 guo). 한 필자는 사실을 다 모으고 나니 가장 쉽게 쓴 기사였다고 말한다.
- **한 사람에서 규모로.** 한 개체의 죽음에서 통계로(P1 yong), 한 사람의 선택에서 가족의 병력, 지역 전체로(P1 reveley).
- **독자를 모르던 사람들의 자리에 놓는다.** 연구사를 시간순으로 풀어 독자가 당혹한 의사들과 같이 알아 가게 한다(P1 reveley).
- **누구의 눈으로 전할까.** 조사한 사람의 어깨 너머로 보게 하면 발견의 감각이 생긴다(P2 hochschild).
- **하나의 이동이 이야기를 끌게 한다**(P2 ehrenreich). 물건이 옮겨 간 길, 사람이 간 길.
- **정점에서 끊고 다른 데로 간다**(P2 junger).
- **남에게 말해 줄 한 순간은 구조를 흔들어서라도 살린다**(P2 mooallem).
- **배경은 필요한 자리에 짧게.** 연구 하나하나를 설명하면 느려진다(P2 jabr).
- **사례는 열둘을 모아도 셋만 싣는다**(P2 junger).

## 5. 어떻게 닫았나

- 처음 만난 사람으로 돌아간다(P2 junger). 시작과 끝을 같은 것으로 평행하게 맞춘다(P1 sokol).
- 사진에서 가져온 한 문장(P2 elmhirst). 사실 한 줄(X2 jstor-zipper).
- 요약하지 않고 한 단계 더 나간다(P2 jabr).
- 핵심 숫자 하나를 끝에 놓는다(K1 jisik-e-kimjinhyuk-peoplepower, 조사자의 관찰). 여운이 남는지가 그날 방송의 평가 지점이다(K1 jisik-e-1000-pdjournal).

## 6. 재미있는 장면과 사실인 장면

이야기를 쫓은 필자들이 사실을 놓지 않은 방식이다.

- 소송 기록으로 그날 밤을 다시 짜면서 진술서에 있는 것만 썼다. 신체 묘사도 성격 묘사도 넣지 않았다(P2 yoffe).
- 직접 보지 못한 장면은 일기, 사진, 책, 그때의 방송에서 가져왔다(P2 elmhirst). 회상된 대화는 다른 사람에게도 물어 맞추거나 그때의 인용과 나란히 놓았다(P2 omeara).
- 결과와 상관없는 일반적인 일은 단정하고, 아무도 모르는 원인은 추정이라고 표시했다(P2 junger).
- 본문에는 출처를 쓰지 않아도, 모든 주장에 출처를 단 표를 따로 냈다(P2 smiley). 한 필자는 2,700단어에 각주 86개를 붙여 냈다(P1 craft-surviving-fact-checking).
- 교열에서 틀린 것이 드러나면 일화를 고치거나 뺐다(P2 roach).

읽히는 것: 이들은 사실을 흐리게 말해서 지킨 것이 아니다. **기록에 있는 것만으로 장면을 짜고, 근거는 화면 밖의 표에 두고, 틀린 것은 뺐다.**

## 7. 반례와 주의

- 이 묶음의 많은 글은 사람을 만나고 현장에 갔다. 이 스킬은 공개된 기록만 연다. 그래서 장면은 기록이 남긴 만큼만 선다. 장면이 서지 않는 주제도 있다.
- 필자들이 단정해서 쓴 것은 그들의 선택이고, 한 필자는 순수주의자의 비판을 받을 수 있다고 인정한다(P2 elmhirst). "단정해도 된다"는 일반 규칙이 아니다.
- 1인칭, 유머, 비유는 이 표본의 매력이지만 취재 단계에서 가져갈 것은 아니다.
- 지식채널e의 제작진은 답을 내지 않고 물음표로 끝낸다고 말한다(K1). 영상 대본 스킬은 물음으로 끝내는 것을 요약과 당부보다 낫게 보지만, 이 스킬은 닫는 줄을 참인 사실에서 먼저 찾는다. 두 방식이 다르다는 것을 적어 둔다.
