# 검수와 넘기기

## 1. 자동 검수

```
python scripts/check_backing.py --backing 받침.json --script 대본.json --verbose
python scripts/check_backing.py --backing 받침.json --script 대본.json --summary 받침_요약.md --sheet 받침시트.html
```

`실패`가 있으면 고쳐 다시 돌린다. 요약과 시트는 실패가 있어도 만들어지지만 맨 위에 실패가 적힌다.

| 항목 | 보는 것 | 수준 |
|---|---|---|
| `sources` | 출처의 칸과 값. 익명 웹이 없는가 | 실패 |
| `source-primary` | 1차 기록, 논문, 공식 통계를 둘 이상 직접 열었는가 | 주의 |
| `coverage` | 대본의 편집 문장과 인용 카드가 모두 판정을 받았는가. 대본에 없는 카드 번호가 없는가 | 실패 |
| `coverage-notes` | 사실을 말하는 표기 카드가 판정을 받았는가 | 주의 |
| `verdict` | 판정과 세기의 값이 맞는가 | 실패 |
| `evidence` | `받쳐진다`인 카드에 출처, 자리, 근거 대목이 있는가 | 실패 |
| `evidence-weak` | 3차 자료나 당사자 발표 하나에만 기대어 `받쳐진다`고 했는가 | 주의 |
| `evidence-single` | 세기가 `단일 출처`나 `다툼`인데 `받쳐진다`이고, 화면에도 판정표에도 구석 표기가 없는가 | 주의 |
| `problem` | 걸린 카드에 무엇이 다른지가 적혔는가 | 실패 |
| `fix` | 걸린 카드에 고칠 길이 하나 짚였고, 그 길에 필요한 칸이 찼는가 | 실패 |
| `label` | 구석 표기가 20자를 넘거나 검수 메모를 담고 있는가 | 실패 |
| `hedge` | 고칠 길이 "~라고 한다", "알려져 있다"로 바꾸라고 권하는가 | 주의 |
| `hinges` | 꺾임 카드마다, 마지막 문장 카드에 반대 서술을 찾은 기록이 있는가 | 실패 |
| `hinge-gap` | 꺾임이 무엇을 뒤집는지 보이는 카드가 있는지 적었는가 | 주의 |
| `quotes` | 인용 카드마다 원문, 말한 이, 대조 여부가 있는가 | 실패 |
| `quote-requote` | 꺾임이나 마지막 한 줄에 놓인 인용이 재인용인가 | 주의 |
| `marks` | `다툼`이면 `disagreements`에, `미확인`이면 `unverified`에 줄이 있는가 | 실패 |
| `visuals` | 화면 자료의 칸. 파일이 실제로 있는가. 이용 조건이 열려 있지 않은 것 | 실패, 주의 |
| `extras` | 덤 재료에 출처와 근거 대목이 있는가 | 실패 |

## 2. 스스로 하는 대조

자동 검수는 칸이 찼는지를 본다. 근거 대목이 그 문장을 정말 받치는지는 보지 못한다. 판정을 다 붙인 뒤 한 번 더 한다(G1).

1. **무거운 카드부터.** 꺾임, 핵심 사실, 마지막 한 줄, 통념을 세운 카드.
2. **근거 대목만 보고 화면 문장을 다시 읽는다.** 그 대목에서 이 문장이 나오는가. 앞뒤 맥락에서 뜻이 달라지지 않는가. 낱말은 같은데 가리키는 것이 다르지 않은가.
3. **`받쳐진다`를 의심한다.** 너그럽게 붙인 판정이 가장 위험하다. 비판하는 사람이 공격할 곳을 먼저 본다: "처음", "유일", "어디에도 없다", 인과를 잇는 말, 누군가의 잘못.
4. **걸린 카드의 고칠 길을 다시 본다.** 더 가벼운 길이 있는데 무거운 길을 짚지 않았는가. 장면을 지우게 하는 길을 짚지 않았는가(`05` 3절).
5. **이름, 날짜, 단위를 따로 본다**(`04` 3절). 외국 이름의 한글 표기는 한국어 자료에서 통용되는 꼴을 찾아 맞추고, 대본이 같은 이름을 두 가지로 적고 있으면 `낱말`로 짚는다.
6. **뺀 것을 묻는다.** 초고가 다루지 않은 반대쪽 사실이 이야기를 거짓으로 만들지 않는가. 그렇다면 `hinges`에 적는다.

## 3. 요약과 시트

- `받침_요약.md`: 판정 집계, 꼭 고쳐야 하는 카드와 고칠 길, 꺾임과 마지막 한 줄이 버티는지, 인용, 덤 재료, 화면 자료, 사람이 직접 확인해야 하는 것. 검사기가 판정표에서 만든다. 손으로 고치지 않는다. 고칠 것이 있으면 판정표를 고친다.
- `받침시트.html`: 카드와 판정, 근거 대목, 고칠 길을 나란히 보는 한 파일. 외부 자원을 쓰지 않는다.

## 4. 돌려주기

- `받침.json`을 대본 스킬에 돌려준다. `achmage-video-script`의 `references/09`가 이것으로 초고를 고친다.
- 사용자에게 짧게 보고한다: 판정 집계, 꼭 고쳐야 하는 카드, 꺾임과 마지막 한 줄이 버티는지, 사람이 직접 열어야 하는 것.
- 고친 대본이 돌아오면 고친 카드만 다시 본다. 고친 문장이 판정표의 근거보다 세지지 않았는지, 구석 표기가 달렸는지, 인용의 말한 이가 바로잡혔는지. 받쳐졌던 카드가 바뀌었으면 그것도 본다.
