# 한 벌의 판단 — case-led continuity study

[180초 본편·35초 A/B·30초 세로판](https://one-garment-motion.achmage2.chatgpt.site/) · [제작 및 검증 기록](https://one-garment-motion.achmage2.chatgpt.site/production-report.json) · [편집 프로젝트와 출처](https://one-garment-motion.achmage2.chatgpt.site/editable-source.zip)

Motion Art Director **4.1.0-rc.2 개발 후보**로 만든 독립 작품입니다. 여섯 촬영 자료와 새로 작성한 그래픽으로 재료 읽기, 구상, 치수, 재단, 연결, 관찰과 수정의 이야기를 구성합니다. 180초·45컷·11시퀀스이며 실사 포함 구간은 약 90초입니다. 여러 자료를 하나의 동일 인물이나 한 벌의 실제 제작 기록으로 표현하지 않습니다.

음악은 사용자가 선택한 **Hazy After Hours — Alejandro Magaña (A. M.), Mixkit**의 기존 녹음만 편집했습니다. 합성 BGM·내레이션·생성 이미지를 사용하지 않았습니다. 음악 및 영상 원본은 편집 소스 ZIP에 포함하지 않으며 자료별 재연결 정보와 이용 조건을 제공합니다.

## 이번에 공통 기능으로 만든 것

- **이어지는 실사 창:** 원본 재생 시간을 유지한 채 위치·크기·둥근 모서리를 절대 프레임으로 계산합니다. 동일한 시간표를 인접 장면과 정지 출력에서 사용합니다. A/B는 같은 소재·음악으로 연결 방식만 비교합니다.
- **컷보다 긴 문장:** 카메라와 장면 전환 뒤의 별도 합성 단계에서 완결된 문장 10개를 유지합니다. 문구만 고칠 때 실사·그래픽·화면 합성은 재사용할 수 있습니다.
- **반복 음악의 구간별 시간표:** 원곡의 같은 시점을 다시 쓰더라도 각각의 사용 구간을 구분합니다. 타격점, 원본 시작점, 배속 변경을 검사하며 단순 음량 수정과 구분합니다.
- **사례를 기획에 적용하는 검색:** awesome-opus5-5-videos의 703개 참고 기록과 16개 자체 기획 레시피를 제공합니다. 참고 기록, 실행 기능, 기술 검증, 미감 확인은 별도 상태입니다. 703개 영상을 전부 시청하거나 703개 효과를 구현했다는 의미가 아닙니다.
- **실제 소스 탐색 증거:** 제공자별 검색 계획과 실제 확인한 결과 URL·접근 실패·선택 이유를 구분합니다. 제공자 수가 곡별 이용 허락이나 청취 확인을 대신하지 않습니다.
- **본편과 파생물의 캐시 공존:** 짧은 세로판이 같은 작업 공간의 긴 본편 캐시를 개수 제한으로 축출하던 결함을 수정했습니다. 자동 개수 한도는 이미 보존한 캐시와 새 작업량을 함께 고려하며, 명시적 제한·바이트 예산·디스크 여유 검사는 유지합니다.

기존 awesome-ai-motion의 637개 카드·128개 클립·11개 레시피와 앞선 Showreel 확장은 유지합니다. 새로운 레시피는 원작의 복제가 아니라 대상·행동·원인·결과·장면 연결을 새 주제에 설계하는 참고용입니다.

## 실행·검수 범위

새로 패키징한 설치본에서 전체 회귀 검사를 실행했습니다. Codex·Claude용 한글/공백 설치 경로, 설치 폴더 밖에서의 실제 CPU 렌더, 문구 변경 후 두 컷과 합성 결과 재사용, 이전 완성본 보존을 확인했습니다. Windows의 긴 생성 경로와 FFmpeg 9 호환 문제도 실제 인코딩 시험으로 수정했습니다.

본편·웹판·비교본·세로판의 프레임 수, 전체 디코딩, 원곡 시간 대응, 마지막 정적은 제작 보고서에 기록합니다. 브라우저 검수는 음소거 원칙을 따릅니다. **전체 청취·사용자 미감 승인·실제 일반 노트북 실측·클라이언트 UI 자동 인식은 자동 검사로 통과 처리하지 않습니다.** 설치 시험은 이 PC의 공통 도구 환경을 사용했습니다.

혼합 영상의 temporal blur는 아직 지원하지 않습니다. 작은 실사 창 다섯 개는 630×354 프리뷰 소재이며, 주된 마네킹 장면은 공식 원본에서 만든 1080p 프록시입니다. 모든 촬영 자료가 HD인 것처럼 표시하지 않습니다.

이 변경은 개발 후보이며, 기존 활성 4.0 설치의 교체나 정식 Release 승격을 뜻하지 않습니다.
