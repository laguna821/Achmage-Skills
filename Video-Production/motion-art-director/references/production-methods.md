# 재사용할 제작 원칙
원본 제작자의 설명에서 방법을 배우되 원 코드의 검증과 설명의 확인을 구분한다. 특정 도구만으로 예술적 품질이 보장되지는 않는다.
1. 입력에서 서사, 인용, 수치, 원어와 시각적 구별 원칙을 추출한다. 본문과 해설처럼 서로 다른 역할은 서체·위계로도 구별한다.
2. 각 장면을 뜻→대상→화면 사건→시간→소리로 적는다. 글자가 문·길·불 같은 대상이 될 수 있다. 무관한 효과 목록을 순서대로 재생하지 않는다.
3. 상태는 절대 시점과 고정 시드로 계산한다. 불씨·재·먼지도 해석식으로 설계하면 임의 시점 미리보기와 구간 합본을 재현할 수 있다.
4. 주요 프레임을 먼저 그리고 겹침·여백·가독성·전환을 수정한다. 실제 관찰이 끝난 뒤 전체를 렌더한다. 반복 횟수를 채우는 것이 목적은 아니다.
5. 정적 배경·비네트·노이즈를 재사용하고, 글로처럼 흐릿한 층은 낮은 해상도에서 계산하는 방식을 검토한다. 프레임 전체를 메모리에 쌓지 않는다. 병목을 측정한 뒤 최적화한다.
6. 영상의 사건 시각을 오디오에도 사용한다. 정지 순간의 무음에는 잔향 버스도 포함해야 한다. 음악 생성과 실제 청취를 구분한다.
현재 패키지는 시간 함수, SVG/text CPU 합성, 윤곽, 컷 캐시, 공유 타임라인 오디오와 이미지 흐름을 구현한다. 물리적인 불·재·체적 연기, 복잡한 글리프 셰이핑, 전용 음향 리버브는 원본 설명과 동일하게 구현됐다고 주장하지 않는다. 필요한 작품에는 별도 대표 컷으로 구현·검증하고 기능 표를 갱신한다.
