# 4.1.0-rc.3 개발 후보

Showreel의 선택 기법을 기존 도감과 제작 흐름에 연결한다. 활성 4.0과 기존 프로젝트 고정을 유지한다.
외부 22개 항목의 대응표와 16개 실행 어댑터를 구분한다. 전체 외부 기법 구현을 주장하지 않는다.

출시 조건: 기존 회귀, 신규 어댑터 출력/입력 반례, 부분 수정, 모션블러 경계,
깨끗한 설치, 공개 패키지 증가 5MiB, 새 통합 작품과 독립 전이 작품 검토.
통합 작품 방향/음악과 전체 청취는 별도 사용자 검토를 거친다.
실제 16GB 일반 노트북 실측과 미감은 자동 검사로 완료 처리하지 않는다.
조건 충족 전에는 개발 후보이며 정식 4.1 또는 활성 OS 업데이트로 표시하지 않는다.

## rc.3: 디렉팅 검증 보강

- 기존 editorial_plan에 선택적 director_brief와 장면별 direction을 연결한다. 기존 프로젝트는 새 필드를 강제하지 않는다.
- director-review는 실제 인코딩본의 전후·접촉 프레임을 먼저 보여주고 기획 의도를 나중에 펼친다. 문서의 주장만으로 미감을 통과시키지 않는다.
- 검토는 프로젝트 지문과 영상 해시에 묶인다. 변경되거나 증거가 없는 기록은 관찰 완료로 집계하지 않는다.
- 글자 정렬·변형 중심의 암묵적 기본값과, 공정 설명이 전체 오브젝트 변형뿐인 장면을 검토 후보로 표시한다. 의도적인 조립 이동을 자동 불합격 처리하지 않는다.
- 직접 제작한 콘티와 이미 선택된 녹음 음원을 지원한다. 압축 콘티에서도 구간 길이 비율을 보존하고 미리보기는 음소거로 시작한다.

실제 제작 검증과 깨끗한 설치 결과는 VALIDATION.md에 따로 기록한다. 버전 표기는 개발 후보의 식별자이며 공개·OS 활성화 증명이 아니다.
