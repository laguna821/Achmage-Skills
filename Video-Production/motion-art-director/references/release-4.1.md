# 4.1.0-rc.1 개발 후보

Showreel의 선택 기법을 기존 도감과 제작 흐름에 연결한다. 활성 4.0과 기존 프로젝트 고정을 유지한다.
외부 22개 항목의 대응표와 16개 실행 어댑터를 구분한다. 전체 외부 기법 구현을 주장하지 않는다.

출시 조건: 기존 회귀, 신규 어댑터 출력/입력 반례, 부분 수정, 모션블러 경계,
깨끗한 설치, 공개 패키지 증가 5MiB, 새 통합 작품과 독립 전이 작품 검토.
통합 작품 방향/음악과 전체 청취는 별도 사용자 검토를 거친다.
실제 16GB 일반 노트북 실측과 미감은 자동 검사로 완료 처리하지 않는다.
조건 충족 전에는 개발 후보이며 정식 4.1 또는 활성 OS 업데이트로 표시하지 않는다.
