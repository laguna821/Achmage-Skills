# Motion Art Director 4.1.0

Showreel의 선택 기법을 기존 도감과 제작 흐름에 연결한 정식판이다. 기존 4.0 작품과 프로젝트의 엔진 고정을 유지한다.
외부 22개 항목의 대응표와 16개 실행 어댑터를 구분한다. 전체 외부 기법 구현을 주장하지 않는다.

기존 전체 회귀, 신규 어댑터 출력/입력 반례, 부분 수정, 순수 벡터 모션블러 경계, 한글·공백 경로의 설치·렌더·수정을 검증했다. 180초 오케스트라와 독립 6초 밸브 작품으로 제작·수정·중단/재개를 실행했다. 정식 ZIP과 재설치 보고서는 Release에 제공한다.

이번 운영 경로는 Achmage MCP → OS 스킬·번들 읽기 → 공통 런타임이다. 독립 Codex/Claude CLI의 설정·쓰기 승인 오류는 별도 호환성 이력이며 이 경로의 출시 차단 조건이 아니다. 전역 클라이언트 설정은 변경하지 않는다.

전체 실제 청취·작품별 미감 승인·물리 모바일 및 16GB 내장 그래픽 노트북 실측은 별도 미검증 항목이다. 정식 배포 승인이나 자동 검사로 통과 처리하지 않는다. Showreel의 Skia 지원과 혼합 영상 temporal blur 등 미지원 범위는 각 어댑터 문서대로 유지한다.

## 디렉팅·시간 계산·수정 보강

- 기존 editorial_plan에 선택적 director_brief와 장면별 direction을 연결한다. 기존 프로젝트는 새 필드를 강제하지 않는다.
- director-review는 실제 인코딩본의 전후·접촉 프레임을 먼저 보여주고 기획 의도를 나중에 펼친다. 문서의 주장만으로 미감을 통과시키지 않는다.
- 검토는 프로젝트 지문과 영상 해시에 묶인다. 변경되거나 증거가 없는 기록은 관찰 완료로 집계하지 않는다.
- 글자 정렬·변형 중심의 암묵적 기본값과, 공정 설명이 전체 오브젝트 변형뿐인 장면을 검토 후보로 표시한다. 의도적인 조립 이동을 자동 불합격 처리하지 않는다.
- 직접 제작한 콘티와 이미 선택된 녹음 음원을 지원한다. 압축 콘티에서도 구간 길이 비율을 보존하고 미리보기는 음소거로 시작한다.

음악 사건의 pulse/onset/accent/phrase/release 역할을 보존하며 반복 녹음의 각 사용 구간에 사건을 연결한다. Skia의 linear/hold/out/smooth easing을 반영하고 segments-v1은 명시한 프로젝트만 사용한다. 긴 작품 → 짧은 파생물 → 긴 작품 수정 시 정상 캐시가 기본 파일 수 제한 때문에 사라지는 결함을 수정했다. 명시적 파일·용량 제한은 유지한다.

703개 참조 사례·16개 자체 기획 레시피는 실행 어댑터와 구분한다. CPU media-container와 post-composite 문장 합성, existing-recordings-only 음악 정책을 포함한다. 실제 제작·회귀·설치 결과와 이전 실패 이력은 VALIDATION.md에 보존한다.
