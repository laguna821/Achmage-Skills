# Motion Art Director 4.0.0

4.0.0은 검증한 제작 기능과 기획 절차를 하나의 공개 패키지로 묶은 버전이다. 프로젝트 형식은3.0.0/3.1.0을 유지하므로 기존 파일을4.0.0으로 강제 변환하지 않는다.

## 포함한 개선

- 실제 음악과 전체 타임라인을 저비용 기획 시청본으로 먼저 검토한다. 무료 소재 제공처별 검색·접근·이용 조건을 구분한다.
- 주제의 보이지 않는 준비·판단·조절을 화면의 대상·행동·결과로 연결한다. 숙련된 동작은 실제 원본 구간으로 검토한다.
- 실사 영상과 SVG/Skia 그래픽을 혼합하고 원본 시계·음악 사건·컷·타이포를 연결한다. 반복 묶음 분석과 사람의 위상 교정을 구분한다.
- 빠른 컷에도 완전한 문장을 유지한다. 원문 잠금·읽기 시간·자산 출처·사건 분류를 보존한다.
- 문구·음원·원본 변경의 영향을 나누고, 중단·재개와 이전 결과를 보존한다. 긴 작품의 작업 캐시는 바이트 상한 안에서 유지한다.
- 도감637개 카드·128개 클립·11개 레시피와 출처를 보존한다. 카드 보유와 실행·자동검사·미감 검증을 구분한다.

## 남아 있는 제한

CPU·Chromium·FFmpeg가 기본이며 GPU·Blender·유료AI API를 요구하지 않는다. 실제 내장 그래픽/RAM16GB 노트북 실측은 미실행이다. 설치 검사와 양쪽 클라이언트의 실제 자연어 에이전트 호출은 서로 다른 검증이다.

음악 자동 분석은 후보를 만들며 청취 승인이나 자동 악기 분류를 대신하지 않는다. 모든 공개 작품의 전체 청취가 자동 검사로 완료되는 것도 아니다. 기존 연구의 미완료 전이시험·일곱 루트 종합 재검수는 별도 기록으로 보존한다.

message-track은 고정 좌표의 vector/hybrid 컷 연결을 지원한다. 움직이는 카메라·중첩 전환과 같은 문장을 독립 합성하는 조합은 미지원 시 명시적으로 거부한다.637개 효과 전체의 실행 또는 미감 검증을 약속하지 않는다.

정적 PDF에는 영상의 대표 프레임·핵심 설명을 남긴다. 발표의 승인된 엔진과 작업별 고정 버전은 유지한다. 별도 생성 이미지 옵션은 사용 환경과 사용자의 선택에 따른다.
