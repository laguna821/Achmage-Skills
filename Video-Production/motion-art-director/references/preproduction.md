# 제작 전 기획 시청과 소재 선정

새 작품의 첫 전달물은 완성도 높은 12–28초 렌더가 아니라 **로그라인 + 실제 음악 2–3곡 + 전체 타임라인 스냅샷 + 이어 읽을 수 있는 카피**다. 기존 대표 컷은 이 단계에서 방향을 정한 뒤 만든다. 사용자 답 없이 음악·미감을 승인한 것으로 기록하지 않는다.

## 적은 비용으로 먼저 버릴 수 있게 한다

1. 주제·독자·한 문장의 약속·정서 변화와 제외 조건을 쓴다.
   [주제 이해](subject-understanding.md)에서 익숙한 이미지에 가려진 조건·판단·조절을 검토한다. 선택곡이 주제의 어떤 면을 살리는지 함께 정하며 포함 항목 수를 품질 점수로 쓰지 않는다.
2. source-search로 음악/영상/효과음 검색 계획을 만든다. 관련 제공처 두 곳 이상을 실제 검색하고 후보·제외·접근 불가를 기록한다. 검색 URL 생성은 검색 완료가 아니다.
3. 곡의 실제 구간과 소재 미리보기 6–12장을 수집한다. 전체 고해상도 영상, 장면별 그림, 합성 효과음, PCM 스템은 아직 만들지 않는다.
4. concept-audition으로 15–60초의 압축 기획 시청본과 전체 이야기 지도를 만든다. 기본 상한은 후보 3곡·16개 구간·960px·5fps·동시 작업 1개. 시간·파일 크기를 측정하되 토큰 수나 고정 완료 시간을 보장하지 않는다.
5. 사용자에게 주제 / 음악 / 문장 톤을 한 번에 판단할 수 있게 보여준다. 폐기해도 원본 자료와 기존 작품은 보존한다. 좋은 후보가 없으면 검색 조건을 바꾼다.
6. 선택 뒤 실제 전체 곡의 구조·시작 위치 교정, 소재 동작 검수, 컷과 문장의 별도 편집, 대표 컷, 본편으로 진행한다.

압축 시청본은 음악의 느낌과 서사 선택용이다. 전체 180초를 45초에 소개하는 영상의 컷 길이는 본편 편집 속도가 아니다. 대표 컷의 미감·정밀 동기화·전체 곡 전개 검토를 대체하지 않는다. 생성 소요와 사람의 결정 시간을 구분한다.

곡/소재별 원본 URL, 저작자, 정확한 조건 URL·확인일·증거, 비용, 사용처, 크레딧, Content ID 상태, 다운로드 가능 여부, 파일 해시를 남긴다. 자동 API가 없는 제공처는 공식 UI 또는 허용된 로컬 파일로 연결한다. 로그인/차단을 우회하지 않는다. 소스 검색 수와 작품 적합성은 별개다.

## 세 개의 시간표

- 음악: 반복 구절, 강세, 여백, 곡의 변화. BPM만으로 구간을 나누지 않는다.
- 그림: 행동과 시점, 컷과 전환. 빠른 컷이 가능하다.
- 문장: 한 생각의 시작·전개·완결과 실제 읽을 시간. 컷마다 지우거나 단어로 자동 축약하지 않는다.

message-track-v1의 units는 완결된 원문과 절대 초 단위 phrases를 가진다. phrases를 합치면 원문이 그대로 복원되어야 한다. 한 구절은 여러 컷을 가로지를 수 있다. message-compile은 기존 vector/hybrid 텍스트 레이어로 이를 분배하여 컷 경계에서 같은 위치·문장이 계속 보이게 한다. 새로운 프로젝트 파일을 만들고 기존 승인은 제거한다.

현재 지원은 **고정 화면 좌표의 일반 컷 연결**이다. 카메라 변형/중첩 전환 위의 독립 자막 합성은 아직 지원하지 않으므로 조용히 흔들리는 자막으로 바꾸지 않고 거부한다. 세로 레이아웃과 글자 줄바꿈은 따로 저작한다. 검사기는 원문·읽기 시간·레이어 변조를 검사하며 이해도·안전영역·미감을 자동 승인하지 않는다.

## 오디오 저장

원본은 공급된 MP3/FLAC/WAV 그대로 한 번만 보관한다. 기획은 압축 AAC 시청본으로 비교하며 WAV 스템을 생성하지 않는다. 정밀 샘플 분석이 필요해진 선택곡만 PCM으로 디코드한다. 믹싱 단계의 PCM·분리 스템은 유지하되 원본/완성본/수정 증거를 캐시와 혼동해 지우지 않는다. FLAC 보관 전환은 무손실 왕복 검사 후 별도 적용한다. 파일 압축이 합성음의 음색을 개선하지는 않는다.
