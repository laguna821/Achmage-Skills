## 패키지 회귀

`npm test`는 release, direction, spatial, automotive, music-direction, ending, publication을 실행합니다. 검사는 실제 브라우저 프레임·FFmpeg 오디오/영상·무음 샘플·순서 변경·캐시와 잘못된 입력의 거부를 포함합니다. 선택 Skia 환경이 없으면 해당 검사만 생략했다고 보고합니다.

렌더 환경의 폰트·Chromium·FFmpeg 설치가 필요합니다. 자동 테스트 결과를 보고 듣는 사람의 미감 평가로 바꾸지 않습니다. 두 클라이언트의 파일 형식·플러그인 검증과 실제 모델 호출 결과도 구분합니다.

## 알려진 표현 제한

- 기본 SVG, 선택 Skia, 이미지 흐름, 공간 확장은 서로 지원 범위가 다릅니다. 미지원 변형은 거부합니다.
- 공간 precision-1의 전환은 shutter만 지원합니다. SVG 장면의 iris와 별개입니다.
- precision-1 타이어 연기 앵커는 현재 세단 좌표에 맞춘 시험 기능입니다. 다른 차종은 별도 구현·검토가 필요합니다.
- 물성 흐름은 이미지/곡선/입자 기반 표현이며 물리 유체 시뮬레이션이 아닙니다.
- CPU 렌더는 실시간 재생 속도를 보장하지 않습니다. 전체 프로세스 최고 메모리와 일반 노트북 성능은 정식판 전 추가 측정 대상입니다.

실제 공개 ZIP 설치 재시험 결과는 Release의 release-verification.json에 기록합니다.
