# Series v2 · 완결 포스터 세트와 독립 A2 인쇄
버전 1.2.0-rc.5. PS06 사용자 교정이 기존 PS03의 5–7장 슬라이드형 해석을 대체한다. 기존 rc6/v1 출력은 그 엔진핀으로 보존하며 신규/명시적 재편집은 v2를 사용한다.

## 먼저 한 장, 필요할 때 독립적인 여러 장
1. 사실 원장을 작성한다. 행사명·목적·일시·장소·대상별 조건·기관 역할·원문 URL을 보존한다. 원본 페이지의 디자인은 복제하지 않는다.
2. 모든 내용을 한 장의 포스터로 먼저 편집한다. 제목·일시/장소·전체 프로그램·연사·참여 정보를 의미 위계와 고밀도 배치로 묶는다. 한 항목 한 장, 첫 장 타이틀만, 마지막 장 신청만 같은 슬라이드 문법을 금지한다.
3. 첫 장에 담기 어려운 추가 원고가 완결된 한 장 분량일 때만 분리한다. 단순 줄 넘침이나 작은 기기 자체가 추가 페이지 이유가 될 수 없다. splitReason에 한 장 편집을 검토한 이유와 장별 초점을 기록한다.
4. 모든 장은 그 장만 봐도 이해되어야 한다. 전체 행사명·핵심 메시지·일시·장소·참여 조건/핵심 맥락을 반복한다. 원고를 처음부터 재배분해 각 장의 고유 상세 내용과 정보량 균형을 맞춘다. 뒤 장을 잔여 문단 보관함으로 만들지 않는다.
5. 화면은 같은 완결 포스터를 실측 재배치하고 종횡비를 보존해 fit한다. 뷰포트 변화로 장 수나 원문을 바꾸지 않는다. 전체 보기의 작은 글자는 크게 읽기/기본 핀치로 접근 가능하게 한다. 실제 CSS px를 보고하고, 한 화면 fit을 읽기 크기 통과로 혼동하지 않는다.
6. 기본 4초 순환은 두 장 이상에만 적용한다. 한 장이면 순환 버튼/진행 막대를 숨긴다. 클릭·초점·수동 이동 후 정지, 숨은 탭/호버 일시 정지, 모션 감소 자동재생 off를 유지한다.
7. 상하단·본문을 authored/light/dark로 동기화한다. 공동기관 로고는 왼쪽부터 일정한 작은 간격의 한 묶음, 같은 시각 높이. 라이트/다크 SVG 별도, 형태·비율·원본 출처 보존, CSS 반전 금지. 도구는 44px ⋯ 하나에 모은다.
8. PDF는 별도 A2 편집. 화면 분할과 인쇄 페이지 수를 자동 연동하지 않는다. PDF 링크를 직접 열고 오프라인은 동일 bytes를 내장한다.

poster.series.schemaVersion=2, composition.mode=complete-posters.
composition.sharedRefs는 모든 장에 반복할 블록 ID. 첫 블록은 전체 title과 핵심 body, 별도 필수 조건/참여 안내 블록을 포함한다. frame.title/date/place 필수.
content 배열은 안정된 id/title, 선택 kicker/subtitle/body/note/items(2열)/url/linkLabel/style(hero/speaker/timetable/attendance).

복수 장에는 충분한 splitReason을 요구한다. 공유 정보를 제외한 상세 분량은 장당160자 이상, 최소/최대 비율0.4 이상. 이는 잔여 조각을 거르는 기계적 하한일 뿐 적정 분량이나 시각 합격의 정의가 아니다. 같은 내용을 테마만 바꿔 장수를 늘리는 것도 거절한다. 전체 의미·관계·조건·장별 초점은 반드시 사람이 읽고 검토한다.
모든 content는 화면과 print.rows에서 모두 참조. 화면 각 장의 sharedRefs 누락·빈 상세·중복 refs·누락 블록은 오류.
print: margin A/B/C, bodySizePt, rows. logos: file/fileDark/name/role/source/provenance/darkProvenance, 양쪽 SVG 안전검사와 공개 SHA. 로컬 경로 공개 금지.

## PS08 · 장 사이 기하 고정
기본 순환은4초이며 명시된 장별 시간은 보존한다. 한 뷰포트에서 모든 장은 같은 논리폭·배율·시트높이·좌우 및 상단 기준선을 쓴다. 후보 폭마다 모든 장의 자연 높이를 측정하고 가장 긴 장으로 공통 fit을 선택한다. 장이 바뀔 때 fit을 다시 계산하지 않는다. 폰트 로드/주소창/회전으로 가시 영역이 바뀌면 전체 세트를 한 번에 재계산한다. 전환은 투명도만 사용하고 이동·확대 애니메이션을 금지한다.

## PS09 · 화면과 종이의 병렬 편집
HTML은 완결 포스터 여러 장을 기본 4초 간격으로 순환한다. 기본 선택은 '라이트·다크 교차'이며 장 번호에 따라 색을 전환한다. authored는 별도 선택이다. 새 저장 키의 명시적 light/dark 선호는 보존하되, 기존 저장 값이 새 기본값을 가로막지 않도록 한다.

모바일 세로 화면은 모든 장의 논리폭·높이·배율·좌우·상단을 공유하면서 본문 가로 점유율 90% 이상을 우선 확인한다. 후보 폭별 실제 표시폭을 우선하고 동률이면 배율을 선택한다. 짧은 가로 화면은 전체 보기와 크게 읽기를 유지한다.

A2는 기본 한 장이다. HTML 장수를 PDF 장수로 복제하지 않는다. 같은 사실 원장에서 별도 2열·다열 편집으로 전체 원고를 한 장에 완결한다. 제목·행사 정보·모든 연사와 주제·일정·조건·출처를 동시에 읽을 수 있는 전통적 포스터 위계를 설계한다. print.rows를 직접 설계한다. print.pages는 사용자가 종이 복수 장을 별도로 명시한 경우에만 allowMultiplePages=true와 multiPageReason으로 허용한다. HTML이 여러 장이라는 이유는 승인이 아니다.

종이 본문 18pt 이상에서 열 너비·중복 정보·제목과 도표 배치를 조정한다. 공간이 부족하면 다시 편집하고 오류를 보고한다. 무제한 축소나 종이 페이지 추가로 해결하지 않는다. academic-one-sheet는 별도 2열 편집·큰 제목·정렬된 공동기관 로고·하단 행사 QR을 제공한다.

print.iccProfile은 명시적 CMYK 출력 ICC 경로다. sRGB 입력색을 LittleCMS 상대 색도계로 변환하고 PDF OutputIntent에 동일 ICC를 내장한다. 작은 검정 본문과 QR은 K100으로 출력한다. 공개 spec에는 경로 대신 프로파일 이름·해시·출력 조건을 남긴다. SVG와 QR의 기본색도 Canvas 경계에서 변환하고 RGB 연산자 0을 검사한다. 불필요한 기본 폰트를 제거하고 남은 모든 폰트의 내장을 검사한다.

인쇄소 지정 프로파일이 없으면 선택한 출력 조건의 준비본(prepared-cmyk)으로 구분한다. 특정 코팅지 ICC는 모든 출력기의 보편 설정이 아니다. 인쇄소·용지 확인 전 press-approved 또는 PDF/X 인증을 주장하지 않는다. 프로파일이 없으면 RGB 교정본(needs-print-profile)이다. 치수·bleed·폰트·원고·색 연산자·프로파일 해시를 preflight에 남긴다. PDF 1장·HTML 2장 회귀 시험을 필수로 한다.

## PS10 · 모바일 HTML 공유 미리보기
순환 포스터에도 공유 이미지를 독립 산출한다. 1200×600 RGB PNG와 내용 해시 파일명, 절대 HTTPS canonical/og:url/og:image·제목·설명·이미지 형식/크기/대체텍스트를 초기 head에 넣는다. A2 전체 인쇄 미리보기를 OG로 재사용하지 않는다.
공개 poster.html은 폰트·PDF를 별도 파일로 제공하고, poster-offline.html은 같은 본문과 PDF를 내장한다. 공개 파일은 share-manifest.json의 명시된 파일·SHA256만 게시한다. 폴더 재귀 복사 금지. 프로젝트 자체 예산은 HTML256KiB/head64KiB/이미지1MiB이며 카카오 공식 크기 제한으로 주장하지 않는다.
생성→시각 검수→게시→공개 HTML·이미지·폰트 HTTP200/형식/크기/해시 및 canonical 확인을 필수로 한다. 일반 UA와 카카오 UA 응답을 비교하되 실제 카카오 수집 성공과 구분한다. 카카오 metadata debugger 로그인/캐시 확인 또는 실기기 카드 확인 전에는 kakao-preview-verified로 표시하지 않는다. 이미지 변경 시 URL도 해시로 바뀐다. 저장된 미리보기 갱신은 공식 도구 https://developers.kakao.com/tool/debugger/sharing 를 사용하며 메시지는 사용자 요청 없이 발송하지 않는다.
