기본 실행은 위 첫 세 문법을 결합한 6열 벤토 어댑터이며, 9개의 동일한 포스터 템플릿을 제공하는 것이 아니다.
UI UX Pro Max 검색의 정보 순서/분류만 사용한다. 검색이 추천한 분홍/세리프/호버효과는 한림 브랜드/인쇄에 맞게 제외한다.
Impeccable의 계층, 인접성, 타이포, 대비, 정렬을 적용한다. 사용자 요청 벤토는 의미별 다른 폭으로 만들며 동일 카드 나열을 피한다.

## 값과 공간
폭 1000 단위, 높이는 mm 비율. 계층형 standard는 바깥40/간격20/안쪽20, compact32/14/14, dense24/8/8. 제목72/60/52, 영역 제목28/25/23, 핵심38/32/28, 본문24/22/20, 조건17/16/15. 실제 글자 폭을 측정하며 세 단계 안에서만 탐색한다. 단순 사진/차트 모드는 별도 고정 프로필을 유지한다. 임의 축소 없음.
제목만 별도로 한 줄 적합성을 측정한다. 기본 auto는 원고의 임의 개행을 공백으로 연결하고,52단위 이상에서 한 줄이 가능하면 선택 프로필의 제목 크기 이내로 맞춘다. 그 이하로 줄여야 하면 기존 크기의 자연 줄바꿈을 사용한다. 화면 후보는 한 줄을 위한 축소를 하지 않는다. 사용자 지정 개행은 titleLayout:preserve로 보존한다.
A0 841×1189, A1 594×841, A2 420×594, A3 297×420, A4 210×297mm. 사용자 지정 세로 크기150~1300mm.
6열 span 2/3/4/6. 행 후보는 6, 3+3, 4+2, 2+4, 2+2+2이며 실제 Pretendard 폭·줄 수·중요도 선호 폭의 비용을 비교한다. 읽기 순서를 유지하고 남은 세로 공간은 중요도에 따라 분배한다. 중요도1은 최소4열, 긴 본문은2열 금지. 상세 규칙은 [고밀도 위계](고밀도-위계.md)를 따른다. 내용이 안 들어가면 산출물 완료를 막는다.
좁은 모바일에서 개요가 작아지는 것은 한 장 축소의 필연이므로 별도 확대 읽기 제공. 모든 본문이 390px 한 장에서 16px가 된다고 약속하지 않는다.

## 화면과 종이
HTML inline SVG + 원본 전체 텍스트 접근성 읽기 + 작은 화면 도구.
T/버튼 테마, Z 확대/맞춤, Esc 복귀. 첫 테마는 OS, 명시 변경은 localStorage. 저장 불가여도 현재 화면은 작동한다.
포스터 도구는 작은 ⋯ 하나로 표시하고 터치 영역은44×44px를 유지한다. 상단 전체 도구 행을 예약하지 않는다. 화면 후보에는 제목 오른쪽 작은 영역만 확보하며 실제 글자·이미지와 겹치지 않는 모서리를 선택한다. 패널 안에 테마·PDF·확대·종이 보기·인쇄·도움말을 제공한다. 바깥 클릭·Esc·초점 이동으로 닫고 사용 중 타이머로 숨기지 않는다. 열기/닫기로 본문을 재조판하지 않는다. 모든 크기에서 toolsClear=true와 실제 화면을 검수한다.
JS가 없어도 SVG 전체 내용 표시. 인쇄 CSS는 도구 숨김, mm 고정, light 강제.
PDF는 동일 좌표의 ReportLab 벡터·임베드 폰트 출력. 일반 RGB/trim 기준이며 CMYK/PDF-X/재단선 검증을 주장하지 않는다.

실제 2배 복합 원고를 모바일/PC에서 눈으로 확인한다. 같은 크기 카드에 긴 문장을 채운 결과를 복합 위계 검수의 통과로 취급하지 않는다.

화면 재조판은 [모바일 화면 계약](모바일-화면계약.md)을 따른다. 종이 좌표와 화면 후보는 분리되며 V로 전환한다. 실제 가시 영역·safe area를 기준으로 원문을 다시 배치한다.

신규 series-v2는 SERIES.md의 PS09 계약이 위 legacy 화면·종이 규칙보다 우선한다. HTML 순환과 A2 한 장 병렬 편집, 교차 테마 기본값, 모바일 폭 점유율 및 CMYK 출력 프로파일 검수를 따른다.
