# 출처와 배포 범위
새 포스터 어댑터와 공개 배포 도구는 저장소의 Apache-2.0을 따릅니다.
외부 자료·글꼴은 각 원본 조건을 유지하며 이를 일괄 재허가하지 않습니다.

| 자료 | 출처 / 조건 |
|---|---|
| CMDS 시각 문법·참고 원문 | Yohan Koo (CMDSPACE), https://deck.cmdspace.work/ . 사이트 footer의 “덱 콘텐츠와 스타일은 복사해 써도 됩니다” 및 출처 표기 지침을 2026-10-09 재확인. 원문 참고 자료를 보존하며 원본 엔진은 실행하지 않습니다. 포스터 적용 원칙은 references/DESIGN.md. |
| UI UX Pro Max | nextlevelbuilder/ui-ux-pro-max-skill. vendor/ui-ux-pro-max/LICENSE (MIT). 검색 코드·데이터·참고 지침 포함. |
| Impeccable | pbakaus/impeccable. references/sources/Impeccable-LICENSE (Apache-2.0)와 Impeccable-NOTICE.md, 기존 Anthropic 출처 보존. |
| Pretendard | orioncactus/pretendard. assets/fonts/Pretendard-OFL.txt. WOFF2와 같은 윤곽·메트릭을 갖는 TTF 포함. |
| Hallym 색상 적용 | references/sources/hallym-DESIGN.md는 공개본용으로 새로 작성한 통합 지침. 외부 로컬 PPT 원문·기관 로고·원본 예제는 포함하지 않습니다. |

source-pins.json에 원문/변환 해시와 출처를 보존합니다. 개인 PC의 절대 경로는 공개본에서 제거했습니다.
비공개 검수 원본은 배포하지 않고 공개 검증 범위와 해시를 구분합니다.
패키지의 기본 출력에는 실제 기관 로고를 임의로 추가하지 않습니다.
