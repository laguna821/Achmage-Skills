## 해석의 한계
위 모바일 크기 검수는 Windows Edge viewport 검사입니다. 모든 실물 iOS/Android 기기를 시험한 것은 아닙니다.
카카오 확인은 해당 URL의 사용자 관측이며 최초 실패 원인·내부 캐시 동작까지 확인한 것은 아닙니다.
ICC 준비본은 PDF/X 인증·특정 인쇄소 승인이 아닙니다. ICC 프로파일은 패키지에 포함하지 않습니다.
문서의 예전 rc 이력은 당시 범위입니다. references/검증범위.md의 미확인 표기는 이 기록과 날짜를 함께 읽습니다.
폰트 준비 전 장수 카운터가 잠시 내부 조각 수로 보이는 기존 표시 이슈는 이번 공유 수정 범위에서 변경하지 않았습니다.

## 공개 패키지 검사
공개 ZIP을 새 폴더로 풀어 84개 파일 무결성·10개 기존 엔진/검사 파일의 원본 일치·개인 경로 미포함을 확인했습니다. Doctor와 최소 series 예제의 실제 HTML/PDF 생성이 통과했습니다. 생성 상태는 시각 검수 대기이며, 이 합성 예제에 별도 디자인 합격을 부여한 것은 아닙니다.

저장소 tools/release.py --check: 소스/ZIP 파일 집합과 바이트 일치.
